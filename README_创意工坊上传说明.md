## 这次更新

v42.20.1.2 是 B42.20 的模块化重构版本：

- 商城、任务、银行、回收、升级、终端、仓库、装填机和机器人等功能已经按独立模块运行。
- 单人和多人复用同一套业务规则；多人只多一层服务端执行与结果同步。
- 删除旧协议、旧服务端总文件和已废弃的控制器、压缩、容量锁等重复运行路径。
- 诊断页现在用于查看模块健康、迁移结果、等待命令和最近问题，普通玩家也可以直接复制高级报告。
- v42.20.1.1 的自带白色像素纹理继续保留，无人机和仓库标记不再依赖其他 MOD 的纹理。

- Mod 自带 1×1 RGBA 白色像素纹理，不再依赖已经从 B42.20 消失的外部 `mask_white.png`。
- 无人机本体、粒子、攻击、守护、灵视和仓库连接标记已经过 B42.20 实机绘制验证。
- 容器角色直接使用系统现有的物品分类，系统把物品识别为“材料”，它在仓库路由中就按材料处理。
- 设置从整件家具改为每个具体储物格独立保存，冰箱、冰柜和其他多储物格家具不会互相覆盖。
- 优先级改成最低、低、普通、高、最高五档；专用角色先于通用角色，同档按较早设置的容器优先。
- 易腐物依次选择有电冷藏、易腐专用、无电冷藏和通用容器。
- 容器管理页显示更接近原版的容器名称，角色、优先级、分类、状态和筛选项使用中文。
- 新增手动“整理仓库”：只整理当前已加载且物理连通网络中的顶层物品，分批执行，支持停止；整理期间锁住仓库存取和设置修改。
- 删除已经没有当前调用的旧压缩恢复、旧世界控制器、旧容量锁、旧上架删除别名、新建死期入口和零调用包装函数。当前交易回滚、多人权限、操作防重及防复制检查保留。

本分支不修改自动装填机业务逻辑，只做回归验证。

## 玩家使用说明

### 1. 主系统与系统币

点击屏幕 GS 悬浮入口打开系统。实体系统币是主要货币，可由击杀、任务、回收和交易获得，用于商城、升级、服务、传送等消费。多人关键经济操作由服务端重新计算和验证。

### 2. 任务

任务页包含待接取、进行中、追踪、进度、倒计时、奖励和失败惩罚。未完成任务可以放弃，放弃按失败处理；角色死亡会令当前进行中任务失败。可开启按游戏小时自动提交已完成任务。

### 3. 商城、抽奖、上架与回收

商城支持分类、搜索、分页和批量购买。玩家回收解锁的商品可以隐藏、恢复，或在隐藏管理弹窗中确认删除；家具使用物品类型和世界贴图共同区分。

原版物品栏中选中物品后右键可执行：

- 回收：出售可回收物，允许处理已经上架的物品。
- 回收并上架：跳过已经上架、不能上架或不能回收的物品。
- 仅上架：只提交商品，不删除物品。

保护物、系统币、钥匙、零价值物和无效物会跳过。抽奖支持全品类、分类、单抽、十连和自定义次数。

### 4. 银行

银行提供活期存取、自动存现金、贷款、还款和三档风险理财。旧存档已有死期可以继续支取，当前版本不再新建死期。钱币整理会尽量把背包零钱换成大面额。

### 5. 升级、天赋与医疗

人物负重升级会按角色当前实际负重接口计算并校准；死亡和重生不会清除已购买等级。升级页还包含属性成长、正面天赋购买、负面天赋移除、感染检查、伤势治疗和病毒治愈。

### 6. 系统空间终端

领取并装备系统空间终端后，可以作为随身回收空间使用。终端支持：

- 查看与多选出售内容；
- 仅回收 / 回收并上架模式；
- 自动回收；
- 容量升级；
- 减重升级；
- 空间减载升级。

内部保护物不参与回收、上架、抽奖或玩家正常计数。

### 7. 系统仓库网络

1. 在系统仓库页领取仓库核心，第一次免费，遗失找回 2000 系统币。
2. 开启连接模式。
3. 右键固定木箱、冰箱、货架等，标记为网络容器。
4. 网络容器必须上下左右紧贴或同格堆叠才能自动连通，不计算斜角。
5. 把核心安装到其中一个网络容器；该容器成为入口，但仍然可以正常储物。
6. 右键核心宿主打开仓库。

仓库页支持人物主背包、合法穿戴容器与整个网络之间多选存取；筛选名称、分类、状态、MOD和来源容器；按实例取出。

容器管理页中：

- 角色决定主要接收哪一类物品；
- 通用容器接收没有更合适专用容器的物品；
- 优先级分为最低、低、普通、高、最高；
- 右键容器行或使用底部按钮均可修改设置；
- 多储物格家具的每个储物格独立设置。

“整理仓库”会按当前角色和优先级重新分配网络中已有的顶层物品。易腐物优先放进有电冷藏容器，且先处理更新鲜的食物。整理只处理当前已加载且连通的区域，最多 20,000 件；关闭窗口后仍会继续，可重新打开查看进度或停止。

### 8. 自动装填机

商城购买自动装填机后，可以把随身散装弹药按弹种存入数字账本，再手动装填随身独立弹匣或取出弹药。快速换弹完成后可自动补充弹匣。枪械内置弹仓不在处理范围内。

### 9. 机器人同伴

单人模式可培养像素战斗无人机，使用跟随、守卫、攻击、灵视、守护和爆裂等能力。多人模式当前不运行机器人战斗逻辑。

### 10. 维护、车辆、家园与快捷栏

修复组件和耐久强化核心用于手持装备；车辆修复模块通过车辆右键菜单使用。家园页可设置家园、回家、返回出发点和临时传送点。系统快捷栏用于常用动作和仓库连接模式。

### 11. 沙盒、管理与诊断

沙盒选项用于新世界初始值，系统管理页用于当前世界的运行时设置。诊断页显示同步状态、等待中的命令和错误信息。服务器和客户端应保持相同 MOD 版本。
