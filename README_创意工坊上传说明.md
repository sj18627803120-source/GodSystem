## 这次更新

v42.20_2.4 基于已发布 v42.20.2.3，保留商城与回收经济整合、人物负重配置和全部现有数值，只修复 B42.20 Java 调用与翻译兼容：

- 新增统一的 B42 Java 调用适配层；自动回收嵌套容器归属、终端容量与减重同步、终端升级、自动装填、仓库、属性、维修和物品识别不再提取 Java 方法后作为普通函数调用。
- 终端容量仍以 49 为原版实例上限；容量、减重、返鲜、空间减载的价格、等级和回滚规则均未改变。
- 按 B42.20.2 官方规则把翻译文本中的字面百分号改为 `%%`；Lua 回退仍向玩家显示单个 `%`。

v42.20.2.3 已包含的修复继续保留：

- 修复 B42.20.2 中自动回收检查的对象方法调用；卖出、终端刷新和嵌套容器归属检查不再重复产生 `getContainingItem` 红字。
- 新增“人物负重首次升级费用”和“人物负重每级费用倍率”，单人与多人结算都读取同一项设置。
- “空间减载每次费用”明确只影响系统空间终端的减载升级，不影响人物负重能力。

以下经济规则保持不变：

- 商城、普通回收、智能回收、终端回收、上架费用和管理员覆盖统一调用同一套报价策略。
- 捆扎钞票等可确定拆包物会递归计算产物回收总价，并在商城售价中加入默认 10% 安全余量。
- 未收录的第三方物品默认回收 1 币，商城售价按系统识别出的食品、材料、工具、武器等分类定价，不再统一使用 550。
- 只有检测到“单物品可动态拆包”、但无法确定产物数量且物品又没有明确价格时，才使用默认 550 风险底价；多材料合成和普通物品创建回调不会误触发。
- 管理页“物品经济配置”可查看定价来源、安全底价和风险警告，并设置商城三态、买价、回收价、分类、抽奖与备注；多选项按钮改为打开完整菜单后直接选择。
- 多人购买和单件上架使用持久操作编号；相同超时请求不会重复扣费或重复发放物品。

以下保留 v42.20.1.8 的快捷键、任务排序和既有稳定功能说明。

v42.20.1.8 是基于已发布稳定版 v42.20.1.7 的最小功能更新：

- 保留 v42.20.1.7 的任务、经济、协议、存档和窗口布局路径，不接入失败的个人仓或全量任务重构。

v42.20.1.7 已包含的渐进式 UI 与终端能力继续保留：

- 只新增两个客户端 helper，不接入 `42.20.1.2` 模块化重构；不修改经济、仓库存取、装填机、机器人或 MP 业务路径。

## 玩家使用说明

### 1. 主系统与系统币

点击屏幕 GS 悬浮入口打开系统。实体系统币是主要货币，可由击杀、任务、回收和交易获得，用于商城、升级、服务、传送等消费。多人关键经济操作由服务端重新计算和验证。

### 2. 任务

任务页包含待接取、进行中、追踪、进度、倒计时、奖励和失败惩罚。未完成任务可以放弃，放弃按失败处理；角色死亡会令当前进行中任务失败。可开启按游戏小时自动提交已完成任务。

### 3. 商城、抽奖、上架与回收

商城支持分类、搜索、分页和批量购买。玩家回收解锁的商品可以隐藏、恢复，或在隐藏管理弹窗中确认删除；家具使用物品类型和世界贴图共同区分。

原版物品栏中选中物品后右键可执行：

- 回收：出售可回收物，允许处理已经上架的物品。
- 回收并上架：跳过已经上架、不能上架或不能回收的物品。
- 仅上架：只提交商品，不删除物品。

保护物、系统币、钥匙、零价值物和无效物会跳过。抽奖支持全品类、分类、单抽、十连和自定义次数。

### 4. 银行

银行提供活期存取、自动存现金、贷款、还款和三档风险理财。旧存档已有死期可以继续支取，当前版本不再新建死期。钱币整理会尽量把背包零钱换成大面额。

### 5. 升级、天赋与医疗

人物负重升级会按角色当前实际负重接口计算并校准；死亡和重生不会清除已购买等级。人物负重的首次升级费用和每级费用倍率可独立设置，不会改变系统空间终端的减载价格。升级页还包含属性成长、正面天赋购买、负面天赋移除、感染检查、伤势治疗和病毒治愈。

### 6. 系统空间终端

领取并装备系统空间终端后，可以作为随身回收空间使用。终端支持：

- 查看与多选出售内容；
- 仅回收 / 回收并上架模式；
- 自动回收；
- 容量升级；
- 减重升级；
- 空间减载升级；
- 返鲜效率升级与返鲜服务（本轮实机未发现明显问题；多人长程、断线重连和服务器重启仍作为后续回归项）。

内部保护物不参与回收、上架、抽奖或玩家正常计数。

### 7. 系统仓库网络

1. 在系统仓库页领取仓库核心，第一次免费，遗失找回 2000 系统币。
2. 开启连接模式。
3. 右键固定木箱、冰箱、货架等，标记为网络容器。
4. 网络容器必须上下左右紧贴或同格堆叠才能自动连通，不计算斜角。
5. 把核心安装到其中一个网络容器；该容器成为入口，但仍然可以正常储物。
6. 右键核心宿主打开仓库。

仓库页支持人物主背包、合法穿戴容器与整个网络之间多选存取；筛选名称、分类、状态、MOD和来源容器；按实例取出。

容器管理页中：

- 角色决定主要接收哪一类物品；
- 通用容器接收没有更合适专用容器的物品；
- 优先级分为最低、低、普通、高、最高；
- 右键容器行或使用底部按钮均可修改设置；
- 多储物格家具的每个储物格独立设置。

“整理仓库”会按当前角色和优先级重新分配网络中已有的顶层物品。易腐物优先放进有电冷藏容器，且先处理更新鲜的食物。整理只处理当前已加载且连通的区域，最多 20,000 件；关闭窗口后仍会继续，可重新打开查看进度或停止。

### 8. 自动装填机

商城购买自动装填机后，可以把随身散装弹药按弹种存入数字账本，再手动装填随身独立弹匣或取出弹药。快速换弹完成后可自动补充弹匣。枪械内置弹仓不在处理范围内。

### 9. 机器人同伴

单人模式可培养像素战斗无人机，使用跟随、守卫、攻击、灵视、守护和爆裂等能力。多人模式当前不运行机器人战斗逻辑。

### 10. 维护、车辆、家园与快捷栏

修复组件和耐久强化核心用于手持装备；车辆修复模块通过车辆右键菜单使用。家园页可设置家园、回家、返回出发点和临时传送点。系统快捷栏用于常用动作和仓库连接模式。

### 11. 沙盒、管理与诊断

沙盒选项用于新世界初始值，系统管理页用于当前世界的运行时设置。已有世界需要在系统管理页修改，不能只改沙盒值。

- 人物负重首次升级费用、人物负重每级费用倍率：只影响人物负重能力升级。
- 空间减载每次费用、空间减载每级增量、空间减载最大值：只影响系统空间终端的减载升级。

诊断页显示同步状态、等待中的命令和错误信息。服务器和客户端应保持相同 MOD 版本。

## 发布前检查

必须运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Test-GodSystem.ps1
```

后续版本、游戏更新或服务器部署时，在 B42.20 实机至少回归检查：

- 单人存入是否严格遵守专用角色和五档优先级；
- 冰箱多储物格是否能独立设置；
- 右键和按钮修改是否立即反映到快照；
- 手动整理、停止、关闭窗口继续、空间不足和断电冷藏；
- 多人管理权限、两人同时操作、重连及服务器重启；
- 自动装填机原有存入、取出、装填和快速换弹行为。
- 返鲜效率 Lv.1/Lv.2/Lv.3 是否分别显示并恢复 25%/50%/100%，且仅影响终端第一层未腐烂 Food；终端内背包和腐烂食物必须跳过。
- 服务页 1/10/20/30 天按钮和右键套餐、关闭重开后的剩余时间、离线不扣时及两人并发购买防重。

后续更新前不要直接合并 `main` 或覆盖稳定备份；先在功能分支完成自动检查和实机验证。
