# GodSystem v1.16.56 像素机器人设计

## 目标

在 Project Zomboid Build 42.19 单人模式中，把当前由双层菱形线框组成的浮游机器人升级为代码内绘制的像素战斗无人机，并增加轻量粒子、真实 0.2 秒蓄能和更自然的移动状态。

本轮不修改物品图标、主 UI、经济数值、目标选择、攻击范围、伤害、五项攻击特效规则、存档结构或多人协议。

## 视觉设计

- 使用 32x24 字符像素矩阵，在模块加载时编译成连续横向像素段。
- 使用两帧悬浮/推进动画和 N、NE、E、SE、S、SW、W、NW 八个方向覆盖层。
- 造型保留菱形能量核心，增加深蓝装甲、青蓝高光、红色传感器和双推进器。
- 核心颜色表达状态：待机蓝白、警戒橙红、蓄能纯红、发射瞬间白热。
- 不恢复机器人 PNG，不修改玩家全局纹理过滤设置。
- 本体控制在约 36 个像素段内；固定粒子池最多 24 个，超出时循环复用最旧槽位。
- 缓存 `mask_white.png` 和缩放后的像素段；逐帧不解析像素矩阵、不创建像素表。

## 行为设计

- `idle`：沿用 2-5 秒停留，核心呼吸，并每 0.8-1.4 秒小幅转向观察。
- `patrol`：沿用当前跟随距离和 1.2 格/秒巡航速度；25% 概率选择距离带近端。
- `catchup`：沿用 4.5 格/秒追赶速度，显示更长推进尾迹。
- `alert/charging`：发现现有合法目标后停止移动、转向并蓄能 0.2 秒。
- `firing/recovery`：发射时创建原有投射物并开始原有冷却，随后后坐并恢复 0.15 秒。
- `guard`：继续在守卫点附近小范围漂移；发现目标时只转向和蓄能。
- 战斗宽限期内复用最近目标位置，每 1.2-2 秒选择一次小幅横移点，不增加僵尸扫描频率。

蓄能结束前重新验证目标、楼层、范围和可见或灵视条件。目标失效、切换停火或环境中断时取消且不扣冷却。所有新增状态都是临时运行时数据，乘车、死亡、召回和关闭功能时统一清理。

## 模块边界

新增客户端模块 `GodSystem_CompanionVisual.lua`，负责像素矩阵编译、缩放缓存、纹理缓存、固定粒子池、机器人绘制和新增粒子绘制。

现有 `GodSystem_Companion.lua` 继续负责玩家/目标验证、移动、攻击、投射物、伤害、技能特效和运行时状态。视觉模块不写存档、不加载服务端代码，也不新增多人协议。

## 验收

- 自动验证版本一致、模块加载、八方向、两帧、粒子上限、蓄能/取消/冷却顺序和清理路径。
- 运行 v1.16.56、v1.16.55、v1.16.53 回归、运行时测试、编码检查和全部 Lua 5.1 编译。
- B42.19 实测主动/防御/停火、全部跟随模式、守卫、缩放、目标失效、隐藏、召回、乘车、暂停和死亡。
- 尸群及五项攻击特效同时运行时，不应出现空白纹理、红字、粒子残留、明显遮挡或持续帧率下降。
