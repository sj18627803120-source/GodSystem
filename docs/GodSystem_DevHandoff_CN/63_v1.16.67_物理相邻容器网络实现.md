# v1.16.67 物理相邻容器网络实现

## 目标与基线

- 开发分支：`fix/v1.16.67-storage-container-network`
- 基线：`research/b4219-placeable-lifecycle@408dc7b`
- 游戏目标：Project Zomboid Build 42.19
- 稳定兼容基线仍为已发布的 v1.16.63；v1.16.67 在 B42.19 SP/MP 实机通过前不能视为稳定发布。
- 本轮只重做系统仓库控制器和容器连接拓扑，不修改现有空间终端、商城、回收、机器人、任务或经济数值。

## 控制器生命周期

- `GodSystem.StorageController` 改为真正的 `base:moveable` 物品，使用原版一格落地贴图 `recreational_01_16`。
- 删除客户端 `ISBuildingObject`、自制安装光标和 `IsoCarBatteryCharger.new()` 路径；安装完全复用原版“放置物品”与 Moveable 拾取流程。
- 网络 ID 与控制器令牌保存在 `item/object:getModData().movableData`；原版拾取创建新物品 ID 后仍按 `networkId + token` 找回原网络。
- GodSystem 右键“收回控制器”会创建新的自定义控制器物品、复制网络身份，再删除世界对象；删除失败则撤销新物品。
- 原版拾取也被允许：只要 B42.19 将 `movableData` 正常带回新物品，控制器仍被识别。
- 每套网络第一次领取免费；再次找回固定 2000 系统币。找回生成新令牌，使旧控制器失效，但不删除网络容器标记或容器内物品。

## 物理容器网络

- 系统页新增“开启/关闭连接模式”。没有控制器也能先标记场景容器。
- 连接模式下右键固定场景容器，可在“标记为网络容器”和“取消网络容器标记”之间切换。
- 标记写在世界家具对象的顶层 ModData，不写进控制器网络的永久坐标列表；一个家具上的全部 `ItemContainer` 槽一次纳入。
- 自动连通规则：同一楼层；上、下、左、右四方向紧贴；同一世界格内上下堆叠；不包含斜角；不跨楼层；控制器自身可桥接位于四周的多个组件。
- 每次打开、刷新、存取或调整连接时，从控制器重新计算当前连通分量，最多 128 个家具节点；不存在每帧、定时或全地图拓扑扫描。
- 家具多个储物槽会在统一仓库中全部索引。冰箱冷藏室、冷冻室等不需要分别进入原版容器界面。
- 旧版逐槽 `network.links` 在首次打开时迁移到家具级标记；已加载且能解析的旧连接保留设置，无法解析的离线坐标记录不再保留。

## 连接模式视觉

- 绿色表示已经与当前控制器连通；蓝色表示已标记但没有与当前控制器连通。
- 颜色只在连接模式显示。开启、右键调整、仓库状态刷新时重算；离开系统仓库页、关闭主窗口/仓库窗口、断线或返回主菜单时自动清除。
- 高亮绘制只遍历玩家同层附近 12 格；连通计算仍遵守 128 节点上限。

## 权限与事务

- 网络容器标记由 SP 共享管理器或 MP 服务端验证玩家距离、楼层、目标对象、真实容器槽和安全屋权限后修改。
- MP 存入/取出仍由服务端移动真实物品；客户端只发送稳定操作 ID 和目标身份。
- 索引、路由、详情、存入、取出在操作开始时重新解析当前物理连通分量。
- 单件转移继续执行来源、目标、容量和原生接受规则复验；失败按原容器、玩家背包、控制器地面三级恢复。
- 远程存取、车辆容器、合成接入、实体线路和自动全仓整理仍未实现。

## 界面

- 系统仓库页首行固定为“使用说明”，点击后在右侧显示完整操作说明，避免左侧长文被省略。
- 系统页可直接开关连接模式；大仓库的“容器管理”页也保留同一开关。
- 删除旧的半径和连接数量加减按钮。物理网络固定最多 128 个家具节点；界面分别显示已连接家具数和储物分区数。
- 仍需靠近控制器右键“打开系统仓库”，进入聚合仓储窗口完成筛选、存入和取出。

- 保存退出、重进后控制器仍能打开。
- 原版拾取后即使 fullType/物品 ID 变化，身份仍能恢复。

- 木箱、金属柜、货架、冰箱/冰柜、上下堆叠家具的实际邻接结果。
