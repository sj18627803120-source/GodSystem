# 42.20.1.3 UI缩放、仓库标记与入口自愈

Status: automated checks passed; B42.20 real-game validation pending.

## 1. 交付身份

- 游戏目标版本：Project Zomboid Build 42.20。
- MOD 版本：`42.20.1.3`。
- Mod ID：`GodSystem_CN`。
- Workshop ID：`3773949382`。
- 开发分支：`fix/42.20.1.3-ui-scale`。
- 起始基线：`main@3c86cfb237550a84186518fa9d3520b6cd2d5188`，即已发布的 `42.20.1.1`。
- 本轮不接入 `42.20.1.2` 模块化重构；只拆出两个客户端 UI helper。

## 2. 修改内容

- 主系统窗口拖拽缩放范围从 `0.75-1.15` 扩大为 `0.60-1.50`。
- 主题最小尺寸同步从约 `930x518` 改为 `744x414`。
- `GodSystem_UI.lua` 内部兜底值同步改为 `0.60` 和 `1.50`，避免主题字段缺失时回到旧范围。
- 窗口打开和拖拽缩放仍使用现有屏幕尺寸夹紧逻辑，不强行超出屏幕。
- 同格仓库容器标记使用 `GodSystem_StorageMarkerLayout.lua`：候选编号 1 固定在最下方，后续编号按同一 x 坐标逐层向上；每个容器只画一个 `^`，不再左右展开、重复绘制或追加竖线。
- GS 悬浮入口使用 `GodSystem_FloatingButtonLifecycle.lua`：每 5 秒只在客户端本地重新注册/恢复入口；仍有效的按钮不重建，失效按钮才创建，玩家拖拽坐标保留，只有完全离屏才自动夹紧。
- 断线或返回主菜单会移除悬浮入口并清空引用，后续进入游戏按当前保存位置重建。
- 不新增服务器命令、状态请求、MP 协议或仓库存取调用。版本号保持 `42.20.1.3`，同步更新 Workshop、上传说明、版本记录和统一测试入口。

## 5. 实机测试点

- 在 1920x1080 下打开主系统，拖到最小、默认、最大三档，确认按钮、左侧导航、列表、详情和底部动作栏没有明显重叠。
- 在 1366x768 下打开主系统，确认最大缩放会被屏幕夹紧，窗口不会跑出屏幕。
- 关闭再打开，确认保存的 `data.ui.windowScale` 会恢复；如果屏幕放不下，会自动降低到可容纳比例。
- 快速切换任务、商城、回收、银行、仓库、说明和诊断页，确认没有黑屏、滚动条错位或按钮重叠。
- 在连接模式下测试同格 1/2/3/4/5 个容器，确认 `^` 使用同一横坐标、从下向上编号，并与右键菜单的编号和状态颜色一致。
- 在 MP 双人长时间游玩后确认 GS 入口保持可见；若游戏 UI 生命周期移除了入口，应在 5 秒内恢复，且不触发额外服务器状态请求。
