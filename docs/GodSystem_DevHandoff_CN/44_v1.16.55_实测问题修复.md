# v1.16.55 实测问题修复

## 实现摘要

- 系统空间终端改用原版 `base:necklace`，删除未通过实机验证的自定义槽注册。
- 左侧导航按当前缩放后的可用高度计算容量，先确定最少页数再均衡项目；按钮使用固定紧凑间距，下翻按钮距底边8像素，单页隐藏翻页按钮。
- 悬浮入口改为 48x48 黑金图标按钮，不再读取或显示系统币；纹理失败时回退为 `GS`。
- 同伴巡航/追赶速度改为 1.2/4.5 格每秒，非战斗到点后停顿2-5秒。目标选择优先可见有效格，找不到时允许附近不可见有效格；本体不可见时仅暂停绘制。
- 灵视范围改为 20/30/40/50 米，守护冷却改为 90/60/40/25 秒。
- 同伴和属性操作在购买前保存稳定 payload ID 与滚动位置，SP 刷新或 MP state 回包后恢复原行。
- 车辆修复模块加入显式 5000 价格。`GodSystemMaintenance.repairVehicle()` 统一执行整车修复、部件统计刷新和同步；MP handler 与新增 SP 命令桥接共用该函数。

## 根因

- v1.16.54 自定义穿戴槽虽然静态字段齐全，但目标 B42.19 实机仍无法穿戴，因此改用原版槽，不继续增加未发布兼容层。
- 导航旧布局将剩余高度平均分配为间距，按钮较少时产生大空隙；固定每页数量也无法适配 UI 缩放。
- 同伴旧移动把可见性当作位置有效性的硬条件，离开视野后无法取得新目标；持续换点且速度偏高又造成一直快速移动。
- 操作后的列表刷新会先清空选择；MP 同步占位行再次刷新时会把原选择 ID 覆盖为空。
- 车辆模块未进入显式价格表，因此使用工具分类兜底价220；SP 客户端直接调用整车修复没有形成稳定的权威执行和同步路径。

## 验证边界

- 自动验证覆盖版本、物品槽、导航结构、图标资源、同伴数值和移动分支、选择恢复、车辆价格与 SP/MP 服务端调用。
- `tools\Test-GodSystem.ps1` 已通过：v1.16.55 专项、v1.16.53 功能/运行时回归、编码检查和21个 Lua 5.1文件编译。
- 项链槽实际穿戴、缩放后的视觉间距、不可见区域徘徊和车辆修复仍需 B42.19 实机确认。
- 当前只保留本地 `feature/v1.16.55` 分支与提交，不推送 GitHub，不生成滚动 ZIP。
