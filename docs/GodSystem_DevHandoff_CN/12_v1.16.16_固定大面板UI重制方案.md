# v1.16.16 固定大面板 UI 重制方案

## 背景

v1.16.14 的 UI 重制失败，表现为只显示少量图标、不显示文字、持续红字。已知风险来自过度重写 render、纹理依赖和 `drawText` 参数里混用多返回值。v1.16.15 已回到 v1.16.13 稳定逻辑，只增加了很保守的主题层，所以肉眼变化不明显。

v1.16.16 的目标是基于 v1.16.13/v1.16.15 稳定功能，做一次真正可见的固定大面板 UI 重制。

## 参考图拆解

参考图的核心不是单个贴图，而是布局结构：

- 顶部横向状态栏：标题、等级/经验、资源、负重、背包、游戏时间、关闭按钮。
- 左侧大导航：每个功能是高行高按钮，选中态有金色边框和深金背景。
- 中部列表：行高更大，选中项有金色描边，右侧显示状态/进度。
- 右侧详情：固定详情面板，分区标题、目标、进度、奖励、惩罚、提示。
- 底部动作栏：当前页面的可执行按钮集中在底部，颜色区分主要/危险/普通动作。

## v1.16.16 落地方案

采用固定窗口而非缩放窗口：

- 默认和固定尺寸：`1240 x 690`。
- 最小尺寸同固定尺寸。
- `resizable = false`。
- 打开窗口时不再读取旧存档里的 `data.ui.windowW/windowH`，避免旧尺寸污染新 UI。
- 关闭时只保存位置，不保存窗口大小。

界面区域：

- 顶部栏：`x=14 y=18 w=1212 h=68`。
- 左侧导航：`x=24 y=100 w=198 h=560`。
- 主列表区：`x=236 y=142 w≈470`。
- 右详情区：`x≈728 y=142 w≈478`。
- 底部动作栏：`x≈730 y≈624`，按钮高度 38。

功能保留：

- 商城、回收、腰包、银行、传送、天赋、任务、升级、记录、说明、诊断页面功能不改。
- 多人轻同步策略不改。
- 任务页仍保留“待接取 / 进行中”两套列表和稳定选择逻辑，只把视觉调整成参考图风格。
- 记录/说明/诊断继续使用单列长文本，避免旧版内容丢失问题复发。

## UI 安全约束

- 不全局 monkey patch ISUI 类。
- 不把网络请求、刷新、任务生成写进 render/prerender。
- 不在 `drawText` 调用中间放多返回值 helper。
- 纹理/图标只做装饰，缺失也不能影响文字和点击。
- 不为了像图添加不存在的业务功能，例如声望、共享任务、查看地图。

## 验收条件

- `GodSystemConfig.Version` 和两个 `mod.info` 都是 `1.16.16`。
- `GodSystem_UITheme.lua` 含固定窗口尺寸和 HUD 布局字段。
- `GodSystem_UI.lua` 中 `GodSystemWindow:new()` 设置 `resizable = false`。
- `GodSystemUI.toggleWindow()` 使用主题固定尺寸，不读取旧窗口大小。
- 顶部状态栏由绘制函数统一绘制，而不是散落的旧 label。
- 导航按钮行高明显变大，窗口肉眼区别于 v1.16.13/v1.16.15。
- Lua 编译、编码检查、命令匹配、目录结构检查通过。
- 创建 v1.16.16 滚动备份，保留最新 20 个版本备份。
