## 最小 SP/MP 实测顺序

### 1. 自动回收与嵌套容器归属

1. SP：把系统空间终端放入主背包、穿戴背包和嵌套背包，分别执行自动回收与出售。
2. MP 主机：重复上述路径，重连后再执行一次。
3. MP 远程玩家：确认同一终端归属判断不误报，其他玩家不影响本人的自动回收。
4. 服务器重启后再次打开终端，确认容量、减重、返鲜和终端归属仍正确。

### 2. 终端升级与失败恢复

- 分别测试容量、减重、空间减载和返鲜升级。
- 检查扣费、升级等级、页面显示和服务端同步。
- 人为制造余额不足或无效终端状态，确认不会扣费或丢失终端，失败后能恢复原状态。
- 容量上限必须仍为原有最大值 `49`。

### 3. 同型 Java 调用路径

- 自动装填机：存入、取出、手动装填、快速换弹补充。
- 网络仓库：节点扫描、分类筛选、存入、取出、整理。
- 人物负重、属性购买、感染检查、伤势治疗、病毒治愈、装备维修和车辆维修。
- 商城物品经济配置：筛选、查看报价、购买、回收，以及 `Base.MoneyBundle` 拆包后的购买—回收闭环。

### 4. 翻译与表现

- 查看利率、返鲜效率、机器人伤害比例和经济安全余量等显示，百分号应只出现一个 `%`。
- 页面切换、打开仓库和刷新列表时不应出现黑页、空列表、持续扫描或明显卡顿。
