# v42.20_3.6 特效注册表与冲击

状态：开发完成，待 B42.20.4 SP / Host / Dedicated 实机验收；未提交、未推送、未上传 Workshop、未创建或替换备份。

分支：`codex/42.20_3.6`。基线：GitHub `main` 的用户验收版 `42.20_3.5`。

## 本轮实现

- 装备强化正式改为有序特效注册表。当前仅注册近战 `freeze` 与 `impact`；枪械仍可绑定、改名、修理、找回、解绑，但装备页明确显示暂无枪械战斗特效。
- 不再读取、计算、应用、恢复或同步伤害、耐磨、攻速、精准、后坐力与配件拆分的旧强化参数。旧档案残留字段不迁移、不清理，也不作为档案错误；旧物品上已经存在的原生数值残留不由 GodSystem 改写。
- 冻结进入统一攻击账本的攻击开始阶段。MP 客户端不再发送旧 `equipmentFreezeSwing`；服务端验证 `equipmentCombatAttack` 后在同一账本内调用冻结权威逻辑。
- 冲击为近战 Lv0–Lv10 独立特效。每件装备保存攻击计数、Ready 和状态修订；达到门槛的攻击只进入 Ready，下一次真实命中以首个活僵尸为中心触发。空挥计数，Ready 后空挥保持 Ready，释放本身不计入下一轮。
- 冲击范围仅遍历中心附近已加载格子，同楼层且半径内选择最近的最多 10 个站立僵尸；每帧最多 64 个对象且约 2ms 预算。调用 `knockDown(false)`，不调用 `Hit`，不额外伤害、经验或耐久。
- MP 服务端决定进度、命中中心和目标；客户端只接收目标列表用于附近模拟/表现补偿，按 session、serial、attackId 去重。
- Tooltip 与装备页改为冻结、冲击专用显示。冻结显示有效减速；冲击显示 `当前/门槛` 或“已就绪”。所有新增文本从 YAML 生成 CN、CH、EN、Lua fallback 与 JSON/txt。

- 已通过：本地化生成（1011 UI 键、33 物品键、88 沙盒项）、全部 111 个打包 Lua 的 Lua 5.1 编译、右键/批量回收、装备、冻结、冲击范围、本地化、导航、任务配置与 UI 安全行为测试。
- 自动测试覆盖：旧字段惰性兼容、注册表、冲击曲线和 Ready 状态、范围最近目标与临时 worker 注销、经济共用、修理/找回/改名/解绑回归。
- 必须实机：`OnWeaponSwing` / `OnHitZombie` / `OnPlayerAttackFinished` 的真实顺序、空挥完成、`IsoZombie.knockDown(false)` 的 Lua 可用性和恢复动画、SP 冻结/蓝色标记回归、Host 与 Dedicated 的攻击包顺序及服务端命中观察、多人僵尸控制权切换、第三方标准近战武器。
