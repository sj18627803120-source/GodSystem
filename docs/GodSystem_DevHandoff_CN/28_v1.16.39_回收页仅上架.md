# v1.16.39 回收页仅上架方案

## 目标

在回收页面给物品右键新增“仅上架”功能。该功能只把当前背包里确实存在的物品加入商城可购买列表，不出售、不删除、不发放回收收益。

## 已确认规则

- 费用为该物品预计商城购买价的 50%。
- 最低费用为 50 系统币。
- 不设置最高上限。
- 已经上架的物品只提示，不扣钱。
- 被黑名单、管理员禁用、回收/商城禁用的物品只提示，不扣钱。
- 支付顺序沿用现有消费逻辑：银行活期优先，然后背包现金。
- 单人模式直接本地验证和扣款。
- 多人模式由服务端验证玩家确实持有该物品、余额足够、物品允许上架，然后扣款并写入服务器持久数据。

## 技术设计

- `GodSystem_Config.lua` 增加 `AutoShopListOnlyCostRatio = 0.5` 和 `AutoShopListOnlyMinCost = 50`。
- `GodSystem_AdminConfig.lua` 把这两个配置加入管理员经济配置，方便服主调整。
- `GodSystem_Core.lua` 增加费用计算和单人执行函数：
  - `GodSystem.getAutoShopListOnlyCost(fullType, sellValue)`
  - `GodSystem.listOnlyAutoShopItem(fullType)`
- `GodSystem_UI.lua` 在回收页右键菜单追加“仅上架”，弹窗说明费用和注意事项，确认后调用执行函数。
- `GodSystem_Network.lua` 在多人模式把 `listOnlyAutoShopItem` 转为 `listOnlyAutoShop` 命令。
- `GodSystem_Protocol.lua` 登记新命令，并将其列入关键操作与状态刷新命令。
- `GodSystem_Server.lua` 增加服务端命令 `Commands.listOnlyAutoShop`，服务端重新扫描背包验证物品存在，不信任客户端传来的价格。
- 本地化新增菜单、确认、提示、历史、管理员配置文案。

## 验证要点

- 回收页右键可以看到“仅上架”。
- 确认弹窗显示费用、购买价、最低价和“不删除物品”的提示。
- 单人：确认后扣款，物品仍在背包，商城出现该物品。
- 多人：服务端验证后扣款，商城同步出现该物品。
- 已上架、余额不足、禁用物品均不扣款。
- 静态测试必须覆盖命令对齐、版本一致、本地化键、Lua 语法、UTF-8 replacement scan。
