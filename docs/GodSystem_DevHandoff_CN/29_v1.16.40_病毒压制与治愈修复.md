# v1.16.40 病毒压制与治愈修复

## 目标

修复升级页医疗服务的感染处理语义：

- `检查感染` 保持现有只读逻辑，不改价格、不改检测口径。
- `压制病毒` 默认价格改为 200，只清空当前僵尸病毒进度，不治愈感染。
- `治愈病毒` 默认价格改为 2000，真正清除僵尸病毒感染状态。

注意：感染进度和是否感染是两层状态。只把进度归零不等同于治愈。

## 实现口径

客户端 `GodSystem_Core.lua` 和服务端 `GodSystem_Server.lua` 保持同构：

- 新增 `*ClearInfectionProgress(body, infectionTimeValue)`：默认把 `setInfectionTime(0)` 和 `setInfectionLevel(0)` 写入，用于压制病毒。
- `压制病毒` 只调用进度清理，不调用 `setInfected(false)`，不再写 `setInfectionMortalityDuration()`，不再读取 `MedicalSuppressInfectionHours`。
- 新增 `*ClearBodyPartInfection(part)`：治愈时清理每个 body part 的感染、假感染和伤口感染层。
- `治愈病毒` 调用进度清理并额外清 `setInfected(false)`、`setIsFakeInfected(false)`、`setInfectionMortalityDuration(-1.0)` 和全身 body part 感染层。

## 配置与本地化

- `MedicalSuppressInfectionCost = 200`
- `MedicalCureInfectionCost = 2000`
- 移除管理员菜单中的 `MedicalSuppressInfectionHours`，避免玩家继续看到已失效的“压制小时”设置。
- CN/CH/Override 文案改为“压制病毒”和“治愈病毒”，并明确压制只清进度、治愈才彻底移除感染。
