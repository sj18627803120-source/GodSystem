## 2026-09-07 20:06 攻击后绘制重载错误

- 用户攻击后触发 `mark:128 No implementation found for function: render`，最新 console 完整异常重复 198 次。直接原因是 Texture + 8 数值的九参数调用没有对应 Java 重载。
- 本机 `projectzomboid.jar` 的 `zombie/core/SpriteRenderer.class` 方法描述符为 `render(Texture;FFFFFFFF;Consumer)V`（简写）；本次所需重载有十个参数，最后为 Consumer 回调。两处标记绘制均补传显式 nil。减速、动画资源、配置及视觉样式不变。
- `media/lua/server/NewSelectionSystem/GridSquareSelector.lua:56` 留有九参数旧调用，该文件的绘制事件注册已注释，不能把文件中存在的调用当作现版本可运行证据。
- 渲染测试原来的宽松 mock 无法检出重载错误；现按实际十参数签名验证数量、数值与最后 nil，修复前复现 `9 ~= 10`，修复后全量 86 组与 107 Lua 5.1 VM 编译、88 项静态检查通过。Kahlua 实际调用和视觉仍待用户复测。

## 已实现

- 装备槽位任务量改为沙盒配置：第 2 槽默认累计 25 次成功领取任务，后续默认倍率 2。公式为 `ceil(基础任务量 × 倍率^(槽位-2))`；第 1 槽免费，基础任务量为 0 时立即解锁配置上限内所有槽位。历史已解锁槽永久保留，降低门槛会立即补解锁。
- 近战绑定装备增加独立 `freeze` 等级，Lv0 起算。它使用既有的系统币、目标成功率、失败降一级、操作 ID 和事务回滚，不另建货币或交易路径。
- 默认开启的实验开关启用后，真实近战挥击（挥空也算）由服务端验证并在玩家周围同层半径 3 格内处理僵尸；推搡、踩踏、徒手与枪械不触发。等级效果为 `min(80%, 等级 × 全局强化百分比)`，默认每级 10 个百分点，Lv8 封顶且禁止继续付费强化。
- 效果持续默认 3 个现实秒。目标仅保留一份临时状态：更强效果覆盖强度，任意后续命中可续时，不叠加也不完全定身；到期、功能关闭、断线／返回主菜单时清除本 MOD 的动画变量。
- 范围搜索是服务端在附近已加载格子上的分帧队列，不扫描全图或背包；每帧最多 64 项并受约 2 ms 协作预算限制。MP 客户端只接收服务端确认的目标／强度／到期时间，在 5×5 的附近格子中恢复本地实体引用，不信任客户端目标名单。
- 生成了 B42.20.4 本机 `zombie` 与 `zombie-crawler` 步行／奔跑／爬行移动节点的命名空间动画派生文件。它们由 `GSFreezePhase` 与专用速度变量选择，不覆盖原版 XML、全局僵尸速度、攻击、倒地或翻越节点。淡蓝标记默认约 0.35 秒，每视口最多绘制 32 个，视觉上限不限制实际效果数。
- 新增六个沙盒选项及 YAML 生成的 CN、CH、Lua fallback：槽位基础任务量、后续倍率、冻结开关、范围、持续秒数、视觉提示。冻结关闭时装备页隐藏该强化入口，已培养等级保留。

## 代码依据与边界

- 原生接口已按本机 B42.20.4 检查：`IsoZombie` 变量、`IsoPlayer` 挥击／推搡／踩踏状态、`GameTime.getServerTimeMills()` 和 `OnWeaponSwing`。`SlowFactor`／`SpeedMod` 不是可靠僵尸移动减速路径，因此没有使用它们或瞬移／击退伪造减速。
- 动画派生是代码确认的接入方式；实际位移比例、控制权切换与第三方僵尸动画 MOD 的兼容性仍必须实机验收。发生动画冲突时不要宣称冻结可用，应关闭该实验开关。
- 性能度量保存在冻结运行时 metrics（队列、格子、对象、条目、耗时、消息量）。自动测试验证的是遍历边界和卸载逻辑，不代表真实 50／200／1,000 僵尸帧时间已经实测。
