# v1.16.46 自动银行、自动任务与风险理财

## 版本边界

- 基线：用户已测试正常的 v1.16.45。
- 实时目录：`C:\Users\Admin\Zomboid\Workshop\GodSystem`。
- 不改变现有买卖、贷款、任务进度、腰包回收和死亡扣款规则。
- v1.15.3 稳定上传包不替换，等待用户进游戏确认。

## 自动操作

- 银行新增 `autoDepositEnabled` / `lastAutoDepositHour`，默认关闭；开启时保存精确世界小时并重新计时，每满1小时把全部随身系统币存入活期。
- 任务新增 `autoTaskClaimEnabled` / `lastAutoTaskClaimHour`，默认关闭；开启时保存精确世界小时，每满1小时批量领取所有已完成任务。
- 状态和最后执行小时写入玩家数据，死亡与重进不清空。
- 固定执行顺序：腰包自动回收、自动交任务、自动存款。
- 空腰包、无完成任务、无随身现金时客户端按小时静默跳过，不发送关键命令；服务端对自动空腰包请求保留无提示兜底。
- SP 自动任务复用 `GodSystem.claimTask(task, true)`；MP 手动和自动任务共用服务端 `claimTaskForPlayer()`，交物品任务由服务端重新检查并移除真实物品。
- MP 使用现有 `pendingKeyCommand` 串行执行，一次只允许一个关键命令；切换与结果使用 `finishCode(code, args, payload)`。

## 风险理财

三个固定汇总账户：

- 稳健：70%上涨1%，25%持平，5%下跌1%。
- 平衡：55%上涨3%，15%持平，30%下跌2%。
- 激进：45%上涨8%，10%持平，45%下跌5%。

共同规则：

- 默认最低投入1币，可从活期或随身现金投入。
- 每个非空账户累计在线24游戏小时结算一次，按当前余额复利。
- 非持平结果至少变化1币，亏损最多扣到0。
- 首次投入后必须完成一次日结才能赎回；之后可部分或全部无手续费赎回到活期。
- 非空账户追加投入不重置计时和赎回资格；账户清空后再次投入重新锁定。
- 理财余额不参与死亡扣款。
- SP 使用本次运行期时间基线；MP 使用服务端内存中的 `investmentOnlineSessions`，重连后重置基线，离线不补算。服务端更新节流按玩家独立计数，避免多人固定回调顺序导致部分玩家永远不结算。

## 旧死期兼容

- `BankAllowNewFixedDeposits=false`；银行 UI 不再调用 `getBankFixedTerms()`，SP 创建函数和 MP 创建 action 也会拒绝新建1/3/7天死期。
- `bank.fixed` 中旧存单继续显示，支持到期或提前支取，收益和惩罚规则不变。

## 管理员配置

- `EnableBankInvestments`：理财总开关。
- `BankInvestmentMinAmount`：最低投入。
- 三档分别提供上涨概率、下跌概率、上涨幅度、下跌幅度。
- 概率以0到100填写；下跌概率最多为 `100 - 上涨概率`，剩余概率自动为持平。压缩后的值直接保存并回显，保证管理员看到的数值与实际结算一致。
- 修改只影响下一次日结，不重置已有余额、进度或赎回资格。
