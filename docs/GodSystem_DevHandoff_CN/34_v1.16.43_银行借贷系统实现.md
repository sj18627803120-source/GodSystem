# v1.16.43 银行借贷系统实现

## 实现范围

本版在银行页新增借贷系统，沿用现有 `performBankAction` / `Commands.bank` 通道，不新增第二套银行入口。

已实现内容：

- 初始额度 2000。
- 每消费 100 系统币增加 5 点额度。
- 同一时间只允许一笔未结清贷款。
- 借款本金直接进入银行活期，不生成实体现金。
- 手动还款和提前结清只扣银行活期，背包现金需要先存入活期。
- 死亡不清除贷款，欠款继续保留。
- 信用破产不清死期存款。
- 破产只写 `loanCreditSpentOffset = data.stats.spentPoints` 来重置成长额度，不直接重置 `data.stats.spentPoints`。
- 多人模式由服务端写入贷款、扣活期、清背包系统币和生成追债僵尸。

## 数据字段

银行数据新增字段：

- `bank.loan`：当前贷款对象，首版只保留一笔。
- `bank.nextLoanId`：贷款编号递增。
- `bank.loanFrozenUntilHour`：破产后借贷冻结到期时间。
- `bank.loanCreditSpentOffset`：破产时记录消费统计偏移，用来清空成长额度。
- `bank.loanBankruptcyCount`：信用破产次数。

贷款对象结构：

```lua
{
    id = "L1",
    kind = "single" or "installment",
    planId = "single" or "i3" or "i5" or "i10",
    principal = 2000,
    createdHour = 1000,
    totalInterest = 100,
    totalDue = 2100,
    paid = 0,
    schedule = {
        { index = 1, dueHour = 1072, principalPart = 2000, interestPart = 100, paid = 0 },
    },
}
```

## 还款规则

一次性借款：3 游戏日后到期，利息 5%。

分期借款：每 3 游戏日一期。

- 3 期：总利息 10%。
- 5 期：总利息 18%。
- 10 期：总利息 30%。

本期还款会支付当前已到期账单和逾期罚息。提前结清会支付已到期账单、逾期罚息、剩余本金和未到期利息的 50%。

## 信用破产

当最早逾期账单超过 `BankLoanBankruptcyGraceHours`，默认 240 游戏小时，会触发信用破产。

破产处理顺序：

1. 计算未还本金、未还正常利息和逾期罚息。
2. 清空 `bank.loan`。
3. 清空 `bank.current`。
4. 清空背包里的 GodSystem 实体系统币。
5. 设置 `bank.loanFrozenUntilHour`，默认冻结 168 游戏小时。
6. 写入 `bank.loanCreditSpentOffset = data.stats.spentPoints`。
7. 增加 `bank.loanBankruptcyCount`。
8. 记录历史并提示。
9. 按欠款每 50 系统币 1 只、最多 100 只生成追债僵尸。

不要在后续版本里把破产实现成 `data.stats.spentPoints = 0`，这会破坏消费任务和历史统计。

## 单人与多人

单人实现位置：

- `client/GodSystem_Core.lua`
- UI 调用 `GodSystem.performBankAction("borrowLoan" / "repayLoanDue" / "payoffLoan")`

多人实现位置：

- `server/GodSystem_Server.lua`
- `Commands.bank` 增加 `borrowLoan`、`repayLoanDue`、`payoffLoan`
- `sendState()` 会调用贷款逾期检查，使打开 UI 或后台同步时服务端能触发破产

`client/GodSystem_Network.lua` 已有 `performBankAction` 包装，会把新动作通过既有 bank 命令发到服务端，不需要新增协议文件。

## UI

银行页新增三类行：

- `bankLoanSummary`：显示贷款额度、可借额度、当前欠款和冻结剩余。
- `bankLoanPlan`：显示短期或分期借款方案，选中后主按钮为“借款”。
- `bankLoanActive`：显示当前贷款，选中后主按钮为“还本期”，次按钮为“提前结清”。

贷款 UI 仍复用银行页底部动作栏，不新增左侧大导航。
