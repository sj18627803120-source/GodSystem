# v1.16.48 沙盒配置、多人理财与右键回收实现记录

## 范围

- 64 项管理员普通设置新增原生沙盒首次默认值。
- 多人风险理财改为客户端在线小时上报、服务端结算。
- 快捷栏拆分腰包回收与腰包回收并上架。
- 隐藏旧回收页，原版库存右键提供精确实例回收。
- 旧回收函数和 `fullType/count` 协议继续保留兼容。

## 沙盒配置

- 生成目标：`42/media/sandbox-options.txt`、CN/CH `Sandbox.json`。
- 来源：`GodSystem_AdminConfig.lua` 的 64 项设置元数据与 UTF-8 YAML 本地化源。
- SP 仅在 `data.adminConfig.settings == nil` 时导入；MP 仅在服务端持久配置 `data.settings == nil` 时导入。
- 系统管理页仍是进入世界后的运行时权威；管理修改不反写沙盒文件。

## 多人理财

- 客户端 `GodSystemNetwork.updateBankInvestmentTime()` 在存在理财余额时维护本次在线世界小时基线。
- 每累计完整 1 小时发送 `bank { action="syncInvestmentHours", hours=N }`。
- 服务端 `applyBankInvestmentElapsed()` 累加所有有余额账户并复用现有 24 小时结算。
- 同步后立即回传 state；未日结时不弹提示。`OnConnected`、`OnDisconnect` 和时间倒退均重置客户端基线，不补离线时间。
- 已移除服务端 `investmentOnlineSessions` 和 `OnPlayerUpdate` 理财计时调用。

## 右键回收

- 入口：`client/GodSystem_RecycleContext.lua`，事件为 `OnFillInventoryObjectContextMenu`。
- 模式：`recycle`、`recycleAndList`、`listOnly`；载荷使用去重后的 `itemIds`。
- 外部容器物品先使用原版库存转移动作移入玩家库存；动作队列末尾追加可回调的 `ISWaitWhileGettingUp` 屏障，避免 `ISGrabCorpseItem` 没有 `setOnComplete()` 时红字。屏障成功后重新验证 ID，再进入 SP 本地结算或 MP `recycle` 命令。
- 回收与回收并上架会删除所选实例；仅上架按唯一 `fullType` 收费且保留物品。
- 系统币、系统腰包、钥匙/钥匙环和经济过滤判定为隐藏/debug/无效的物品受到保护。
- 非空容器必须确认 `allowDestroyContents=true`；确认时记录递归内容实例签名，执行端签名不一致则取消。确认通过后删除外层及内容，收益只计算外层。
- 删除手持或穿戴实例前清除对应引用；`Remove()` 后再次检查原容器，失败时不发币并恢复已处理实例与装备状态。

## 快捷栏

- `腰包回收` 固定调用 `recycleWaist`。
- `腰包回收并上架` 固定调用 `recycleWaistAndUnlock`。
- 两个动作不读取或修改腰包页模式；快捷窗高度扩展以容纳最多五个动作。
