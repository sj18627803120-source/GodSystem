# v1.16.45 腰包回收模式与中文治理

## 目标

- 实时测试目录升级到 `v1.16.45`：`C:\Users\Admin\Zomboid\Workshop\GodSystem`。
- 腰包空间新增独立回收模式，和普通回收页的 `recycleUnlockMode` 分离。
- 多人新触及提示改为服务端发送 `code/args`，客户端用 `NotifyMP_*` 本地化。
- 新增本地化源与生成器，避免继续手写 Lua fallback 中文。

## 腰包模式

- 新增数据字段：`waistRecycleUnlockMode`，缺失时按 `false` 初始化，也就是默认“仅回收”。
- 普通回收页仍使用 `recycleUnlockMode`，不影响腰包页。
- 腰包页第五个按钮改为模式按钮：
  - `模式：仅回收`
  - `模式：回收上架`
- 腰包页主按钮/副按钮随模式切换：
  - 仅回收：`出售选中` / `出售全部`
  - 回收上架：`出售并上架选中` / `出售并上架全部`
- 手动选中、手动全部、快捷栏“卖腰包”、自动腰包回收都走同一个模式判断。

## 单人路径

- `GodSystem_Core.lua` 初始化和保存 `data.waistRecycleUnlockMode`。
- 新增：
  - `GodSystem.isWaistRecycleUnlockMode()`
  - `GodSystem.toggleWaistRecycleUnlockMode()`
  - `GodSystem.recycleWaistSpaceItemsByMode(selectedFullTypes)`
- 单人自动腰包回收从固定 `recycleWaistSpaceItems(nil)` 改为 `recycleWaistSpaceItemsByMode(nil)`。

## 多人路径

- `GodSystem_Protocol.lua` 新增 `toggleWaistRecycleMode`，并加入 `StateCommands` 和 `KeyCommands`。
- `GodSystem_Network.lua`：
  - `toggleWaistRecycleUnlockMode` 发送 `toggleWaistRecycleMode`。
  - MP 自动腰包回收按 `data.waistRecycleUnlockMode` 选择 `recycleWaistAndUnlock` 或 `recycleWaist`。
  - `Result/Notify` 优先读取 `{ code, args }` 并使用 `NotifyMP_*` 本地化，保留旧 `message` fallback。
- `GodSystem_Server.lua`：
  - 初始化 `data.waistRecycleUnlockMode`。
  - 新增统一 `finishCode(player, ok, code, args, payload)`。
  - 本轮触及命令不再发送中文整句结果：`claimWaist`、`upgradeWaist`、`toggleWaistAuto`、`toggleRecycleMode`、`toggleWaistRecycleMode`、腰包回收内部路径。
  - `Commands.toggleWaistRecycleMode` 切换后回传 state 和本地化 code。

## 中文治理

新增源文件和生成器：

- `tools/godsystem_v11645_localization.yml`
- `tools/generate_godsystem_v11645_localization.py`

规则：

- 新增 UI/提示文案先写 YAML 源。
- 运行生成器写入：
  - `Translate\CN\IG_UI_CN.txt`
  - `Translate\CH\IG_UI_CH.txt`
  - `GodSystem_Localization_Override.lua`
- Translate 文件保留 UTF-8 中文和行尾逗号。
- Lua fallback 写成 ASCII-only UTF-8 字节转义，例如 `\229\...`。
- 不用 PowerShell 控制台显示判断中文是否损坏；要用 UTF-8 读取和专项测试判断。
