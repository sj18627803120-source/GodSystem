关键结构：

- `mod.info`：根 mod 信息，Workshop 和本地识别都需要。
- `42\mod.info`：Build 42 分支信息。
- `42\media\lua\client\GodSystem_Core.lua`：核心逻辑，货币、回收、任务、腰包、传送、天赋等。
- `42\media\lua\client\GodSystem_UI.lua`：主 UI、悬浮窗、任务追踪 UI、按钮布局。
- `42\media\lua\shared\GodSystem_Config.lua`：版本号、经济参数、商店、任务、腰包、传送、天赋价格等配置。
- `42\media\lua\shared\GodSystem_Prices.lua`：原版物品价格表。
- `42\media\lua\shared\GodSystem_Localization.lua`：Lua 字符串 fallback。
- `42\media\lua\shared\GodSystem_Localization_Override.lua`：额外汉化覆盖。
- `42\media\lua\shared\Translate\CN`：简体中文翻译。
- `42\media\lua\shared\Translate\CH`：兼容另一中文目录。
- `42\media\scripts\GodSystem_Items.txt`：系统币、系统空间终端和仓库核心物品脚本。普通系统币和仓库核心都使用 `ItemType = base:normal`；核心不带世界家具、模型或容量属性。
- `42\media\lua\shared\GodSystem_Storage.lua`：仓库身份、核心宿主容量事务、相邻拓扑、索引和物品搬运原语。
- `42\media\lua\shared\GodSystem_StorageManager.lua`：SP/MP 共用的核心领取、安装、取回、找回、迁移、权限与网络事务。
- `preview.png`：创意工坊预览图，不带版本号，后续继续复用。

打包结构必须长这样：

```text
GodSystem_vX.Y.Z_B42_WorkshopUpload.zip
├─ Contents
│  └─ mods
│     └─ GodSystem
│        ├─ mod.info
│        └─ 42
│           ├─ mod.info
│           └─ media
└─ preview.png
```

不要把 `GodSystemMod` 外层开发目录直接当作上传目录。

注意：

- 当前稳定包 zip 第一层必须直接是 `Contents`、`preview.png`、`workshop.txt` 等文件。
- 不要额外多包一层 `GodSystem` 外壳目录。
