# v42.20_3.12：拟态钥匙与性能评估

## 本版功能

- 新增 `GodSystem.MimicKey`，商城工具类基础价 1000。它是原版 `base:key`，使用空白钥匙图标、钱包兼容标签，并排除自动上架及回收。
- 对已上锁的原版门、双开门、车库门生成 `Base.Key1`；门尚无 KeyId 时由权威端生成，并同步同组门。目标保持上锁。
- 对钥匙挂锁对象生成 `Base.KeyPadlock`；对密码锁清除密码并返还 `Base.CombinationPadlock`；对至少有一扇已锁车门的车辆调用原版 `createVehicleKey()`。车辆保持上锁。
- 客户端仅提交拟态钥匙 ID 与目标稳定标识。多人服务端重查物品、距离、楼层、锁状态与对象，使用 `opId`、指纹和持久化回执防止重发重复消耗。单人和多人共享目标识别及转换业务实现。
- 结果固定进入玩家主背包。允许重复制造相同钥匙。标准 `IsoDoor`、`IsoThumpable`、KeyId 和车辆钥匙接口的模组对象可自然兼容；自定义锁脚本仍需实机确认。

## 性能评估（3.7–3.12）

| 版本 | 常驻开销 | 峰值/一次性开销 | 结论 |
|---|---|---|---|
| 3.7 负重 | 每秒按在线玩家读取和必要时写入标量 | 无背包扫描 | 低，随在线人数线性增长 |
| 3.8 任务、动态经济 | 任务约 5 秒一次；经济约 30 秒分批清理最多 8 条 | 接取/结算时的已有验证 | 低到中，不遍历离线账号或完整商城 |
| 3.9 死亡保护 | 仅单人且有次数时约 500ms 检查生命 | 触发时限定同层、30 格、最多 80 候选点 | 常驻低，救援时有受控短峰值 |
| 3.10 商城 | 稳定页只处理当前 20 项，图标缓存最多 512 项 | 首次目录分批排序与构建 | 首次中等，缓存命中后低 |
| 3.11 大批回收 | 无新增常驻轮询 | 排序、删除实际物品、计算摘要 | 当前最大一次性开销；摘要解决存档/网络膨胀 |
| 3.12 拟态钥匙 | 无 `OnTick`/`OnPlayerUpdate`、无世界扫描 | 右键命中相关目标后一次物品查找；执行时一次物品定位和目标解析 | 常驻近乎零，单次低 |

现有 Lua 模拟的 10,000 件完整回收交易约为 SP 1.1 秒、MP 1.7 秒，包含模拟删除及交易流程，不能替代游戏内帧耗时。3.11 主要降低操作 ID、回执和存档大小，物品删除的线性成本仍存在。

拟态钥匙新增专项检查：无目标与未上锁目标不扫背包；命中受支持目标时只查找一次拟态钥匙；菜单不发网络请求；没有后台事件；请求与回执仅保存物品 ID 和目标坐标/索引或车辆 ID。
