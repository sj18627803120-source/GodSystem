# v1.16.69 自制 Moveable 控制器修复

## 修复目标

本版只处理 v1.16.68 实机暴露的两项阻塞问题：

1. 普通地面物品没有原版家具安装/拾取生命周期，控制器落地后无法稳定触发 GodSystem 右键。
2. 连接模式逐帧执行 `next(Context.markers)`，B42.19 Kahlua 中该调用为 nil，触发 `Object tried to call nil in renderMarkers`。

仓库网络、容器邻接、索引、存取、经济和找回规则不改。

## 依据与结论

依据优先级遵循项目既定规则：

1. B42.19 游戏设备研究已经确认：稳定方案应使用原版 Moveable 生命周期，普通地面物品与客户端 `ISBuildingObject` 路线均不适合继续扩展，见 `62_B42.19_可安装物品生命周期研究.md`。
2. v1.16.67 的 B42.19 实机结果证明 `base:moveable` 能进入原版放置和世界右键流程；当时名称变成“奥兹博士游戏机”，原因是借用了 `recreational_01_16` 的原版家具身份，而不是 Moveable 路线本身失效。
3. B42.18 原版 `ISMoveableSpriteProps.lua` 明确读取 `IsMoveAble`、`MoveType` 和 `CustomItem`；放置时把物品 `movableData` 复制到世界对象，拾取时再复制回物品。`CustomItem` 存在时，原版直接实例化指定物品类型。
4. 同代公开 MOD Useful Barrels 的 B42 自定义 tile 使用 `IsMoveAble + CustomItem + CustomName` 返回自己的物品，证明自定义贴图包和自定义物品身份可以组合使用。

因此本版采用“专用 tile + `CustomItem = GodSystem.StorageController` + 原版 Moveable”的最小方案，不复制任何参考 MOD 的贴图或业务代码。

参考：

- B42.18 原版镜像：`https://github.com/mitcaka/PZ-42.18/blob/master/lua/shared/Moveables/ISMoveableSpriteProps.lua`
- B42 Useful Barrels tile 源：`https://github.com/GigaWatte/UsefulBarrels/blob/master/Contents/mods/UsefulBarrels/42/media/UB_tiledefinitions.tiles.txt`

## 控制器外观和资源

- 物品仍为 `GodSystem.StorageController`。
- `ItemType` 改为 `base:moveable`。
- `WorldObjectSprite` 改为专属 `GodSystem_StorageController_0`。
- 删除 `CarBatteryCharger` 静态地面模型，不再借用 `recreational_01_16` 街机贴图。
- 专属 tile 为 128×256 RGBA PNG，黑蓝机柜、青色屏幕、暗金边框和菱形核心；没有文字、街机标志、碰撞或容器容量。
- tile 属性只保留 `BlocksPlacement`、`CustomItem`、`CustomName`、`IsMoveAble`、`MoveType = Object` 和 `PickUpWeight = 20`。

资源文件：

- `42/media/texturepacks/GodSystemStorageController.pack`
- `42/media/GodSystemStorageController.tiles`
- `42/media/GodSystemStorageController.tiles.txt`
- `tools/assets/storage-controller/GodSystem_StorageController.png`
- `tools/assets/storage-controller/Build-StorageControllerAssets.ps1`

`mod.info` 注册：

```text
pack=GodSystemStorageController
tiledef=GodSystemStorageController 9169
```

源图使用 Codex 内置 ImageGen 生成，再以色键去背并用最近邻缩小成最终 tile。生成提示概要：Project Zomboid B42 一格等距像素家具、紧凑黑蓝未来仓库控制器、青色屏幕、暗金边框、菱形核心、无文字、无 Logo、无阴影、纯洋红色背景。最终源图和处理后 RGBA 图均保存在 `tools/assets/storage-controller`，构建脚本可以重建 pack 和 tiledef。

## 身份和生命周期

控制器网络身份继续只使用 `movableData`：

```text
GodSystemStorageNetworkId
GodSystemStorageControllerToken
GodSystemStorageControllerInstalled
```

原版 Moveable 在放置和拾取时负责复制 `movableData`，GodSystem 继续负责身份识别、右键打开/收回、权限复验、2000 系统币找回、黑名单保护、网络发现、索引和存取。物品 ID 仍不作为永久网络身份，拾取后生成新实例不影响网络。

## 连接模式红字修复

`GodSystem_StorageContext.lua` 新增缓存计数 `Context.markerCount`：

- 刷新标记时新增对象才递增；
- 清理标记时归零；
- 逐帧绘制只判断 `markerCount <= 0`；
- 不再调用 `next(Context.markers)`；
- 不增加逐帧场景扫描、周期扫描或对象闪烁高亮。

## B42.19 实测清单

1. 领取后背包名称必须为“系统仓库总控制器”，不能出现“奥兹博士游戏机”。
2. 背包右键应进入原版家具放置光标，不是普通“放置物品”掉地。
3. 安装后显示黑蓝自制控制器，不出现街机交互。
4. 世界右键显示“打开系统仓库”和“收回系统仓库控制器”。
5. 开启连接模式不出现 `renderMarkers` 红字，只显示绿/蓝菱形标识。
6. 标记相邻木箱后刷新，预先放入的木板必须显示。
7. 原版拾取和 GodSystem 收回都应保留网络身份；重新安装后按新位置发现连接。
8. 保存退出并重进后重复 3—7。
9. MP 主机和远程玩家分别重复放置、打开、收回与重连。
