# v42.20_3.11：大批回收回执与终端设置

## 已实现

- 新增共享 `GodSystem_RecycleFingerprint`。回收请求先按旧规则规范化：模式、销毁容器内容标记、排序后的物品 ID（重复项不合并）和排序后的容器签名。
- 物品 ID 数量不超过 2,000 时继续写入旧完整指纹；超过 2,000 时以双 31 位滚动摘要写入 `h:<数量>:<摘要A>-<摘要B>`。摘要直接流式处理规范化字节，不创建完整 ID 字符串，长度不超过 64 字节。
- 客户端多人重试和服务端交易回执调用同一共享 helper。旧版大型完整回执在所属回收交易桶第一次载入时压缩为同一摘要，因此同操作 ID 的原请求仍能回放；内容不同仍会被拒绝。
- 终端新增大（1700×1000）、超大（1920×1080）、满屏（屏幕内留 12 像素边距）窗口。旧偏好保持有效，未知尺寸回退自动适应。
- 字体维持本终端独立的小／标准／大选择；设置页显示当前原生行高像素值。没有改写游戏全局字号。
- 任务页标签改为待接数量与进行中/有效上限，任务扩展页也保持显示。统计使用当前任务状态，不新增轮询、网络请求或背包扫描。
