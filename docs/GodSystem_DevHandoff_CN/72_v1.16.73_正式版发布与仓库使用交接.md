## 系统仓库怎么使用

1. 打开 GodSystem，进入“系统仓库”。
2. 第一次免费领取系统仓库核心；遗失找回固定消耗2000系统币。
3. 开启连接模式，右键固定箱柜、冰箱、冰柜或货架，将其标记为网络容器。
4. 网络容器需要上下左右紧贴或在同一格堆叠；斜角不连通。
5. 把仓库核心安装到其中一个网络容器。核心宿主既是仓库入口，也继续作为普通储物容器。
6. 右键核心宿主打开系统仓库，可在人物背包、合法穿戴容器和整个已加载连通网络之间存取。
7. 在“容器管理”中给每个真实储物格设置角色和最低、低、普通、高、最高优先档。
8. 物品先进入与系统分类一致的专用角色，再进入通用角色；同一角色优先档越高越先使用。
9. 冰箱等多储物格家具分别设置，修改冷藏格不会覆盖冷冻格。
10. “整理仓库”会按当前规则重新整理已加载连通块中的顶层物品；关闭窗口后仍可继续，重新打开可以查看或停止。

仓库不会把物品变成虚拟数字。每件物品仍真实存在于原版家具容器中。区域未加载时，那部分物品暂时不会出现在仓库索引里；玩家回来并刷新后重新加入。

## 下一版开发流程

1. 拉取 GitHub `main`，确认基线为 `v1.16.73`。
2. 从 `main` 新建独立功能或修复分支。
3. 先查 B42 当前游戏接口、现有调用链和相关专项测试。
4. 只在 Git 工作树修改，不直接编辑旧 Workshop 快照。
5. 修改本地化时先改 UTF-8 YAML 源，再运行生成器。
6. 交付前运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-GodSystem.ps1
```

7. 自动检查通过后再部署到游戏目录实测；用户确认后才能合并 `main` 和建立新版本标签。
