## 当前运行时入口

- `client/GodSystem_Core.lua` 安装 ClientRuntime 的 Foundation、BankGrowth、MedicalTraits、Economy、Home、Recycle 与 Tasks 模块。
- `server/GodSystem_Server.lua` 安装 ServerRuntime 的 Foundation、Bank、EconomyTasks、RouterConfig、Commerce、Lottery、Services、HomeGrowth、RangeRecycle 与 Background 模块。
- `client/GodSystem_UI.lua` 安装 UI_Runtime 的 Components、Window、Lists、Pages、Details、Dialogs、Actions 与 Lifecycle 模块。
- `shared/GodSystem_RuntimeConfig.lua` 与 `42/media/sandbox-options.txt` 是运行时沙盒配置路径；不要重新加入已删除的 `GodSystem_AdminConfig.lua`。

新增功能或修复必须先沿上述 bootstrap 路径定位服务归属，再确认 B42.20 原版接口和 SP/MP 权威边界。旧 v1.16.x 文档对已删除 Storage 实现的描述仅作历史背景，不能作为文件路径或调用链依据。

## 本轮修复：沙盒本地化生成

同步后的 `tools/localization/generate_godsystem_v11645_localization.py` 仍读取已删除的 `GodSystem_AdminConfig.lua`，因此生成命令会在打开文件时失败。其旧逻辑还固定要求 73 项设置，而当前 `sandbox-options.txt` 定义 70 项。

修复后：

- 生成器直接解析 `sandbox-options.txt` 中的实际 `GodSystem.*` 选项和翻译键，不写回选项定义或默认值。
- 每项现有沙盒设置都强制要求 YAML 同时拥有 `AdminSetting_<Key>` 与 `AdminSetting_<Key>_Desc`。
- 补齐范围回收、经济安全参数、贷款、家园安全区、医疗和同伴性能设置等 27 项 YAML 标签/提示。
- 重新生成 CN/CH Sandbox JSON，移除错误重复的分类前缀；其它 CN/CH Translate 与 ASCII-only Lua fallback 仍由同一 YAML 生成器同步。

日常生成命令：

```powershell
& 'C:\Users\wan20\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' .\tools\localization\generate_godsystem_v11645_localization.py
```

如果开发机的 Python 路径不同，使用任何 Python 3 运行同一脚本即可。修改本地化时先改 YAML，再生成并审查全部生成文件；不要直接修改生成输出后遗漏 YAML。
