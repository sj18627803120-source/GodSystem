# 功能现状

当前状态：v1.15.3 仍是保留的稳定上传备份；实时开发/测试目录已迭代到 v1.16.63。v1.16.63 空间减载已完成静态、运行时和 Lua 5.1 编译验证，B42.19 SP 升级减载主路径已由用户实测通过；MP同步、重连和扩展场景仍待测试。

核心功能：

- UI：v1.16.18 起主界面为 1240x690 暗金大面板，顶部资源状态栏、左侧大导航、内容列表、右侧详情和底部动作栏按参考图方向重排；v1.16.26 起主窗口可右下角拖拽等比缩放，保持 1240x690 设计比例，最小 75%，控件、列表、按钮和背景同步缩放，并保存缩放比例。任务页列标题已下移避免与页面标题重叠，任务行改为紧凑标题、进度/剩余时间和进度条；记录/说明/诊断移到标题栏工具按钮。v1.16.20 起列表不再鼠标悬停自动选中，左键/右键点击才改变选中。v1.16.21 起重建普通列表时重置 `ISScrollingListBox` 滚动状态；v1.16.22 起固定布局改宽高后同步子滚动条几何；v1.16.23 起主列表、详情列表、任务进行中列表都安装安全 prerender，避免所有需要滚动的 GodSystem 列表出现中间黑屏但数据/详情仍存在。v1.16.14 的失败实现仍不作为基线。
- 悬浮窗：可移动，点击打开主系统。
- 系统币：使用实体物品作为货币，避免 ModData 存档丢失导致点数归零。
- 商城：可购买初始基础物资，也可购买回收解锁后的物品；购买后按商品 id 恢复当前选中，不应跳回第一项。v1.16.27 起多人分类抽奖成功后应弹出解锁结果，已解锁商品列表优先显示本地化物品名。
- 多人击杀奖励：每只僵尸仍为 1 系统币，但多人模式会批量同步击杀差值。v1.16.28 起弹窗显示“击杀奖励合计 +N 系统币”，其中 N 是本次同步合计，不是随机单杀奖励。
- 商城分类：按物品第一个标签归类，避免商店列表太乱。
- 商城抽奖解锁：按分类随机解锁未上架物品，带确认和结果提示。
- 回收：扫描玩家物品，可卖出物品换系统币；v1.16.20 起复用搜索框过滤回收列表。
- 回收模式：解锁模式会把回收物品加入商店，回收模式只卖不解锁。
- 经济：当前回收价一般为购买价的 1/20，低价物品保底 1 币；v1.16.19 起散装弹药回收固定为 1 币，避免盒装弹药拆开后套利。v1.16.25 起系统消费统一按“银行活期优先，不足再扣背包实体系统币”处理；死期不参与直接支付。银行存入活期、现金存死期仍只扣背包实体币。
- 系统空间终端：v1.16.55 使用原版 `base:necklace` 作为 `BodyLocation` 与 `CanBeEquipped`，继续使用透明无模型 ClothingItem；只识别 `GodSystem.SystemSpaceTerminal`，不再兼容未发布旧腰包或自定义测试穿戴槽。
- 终端升级：原生容量最高 Lv.8，数值为10/15/20/25/30/35/42/49；减重独立升级至99%。新增空间减载，默认每次2000币增加5点、最高2000点，通过隐藏受保护的内部 Food 负重量提供约2049等效空间；三项参数可在沙盒和系统管理页调整。
- 终端自动回收：单人保持本地计时；多人由客户端按 1 游戏小时根据终端模式触发 `recycleWaist` 或 `recycleWaistAndUnlock`，服务端验证系统空间终端和真实物品后执行。
- 任务：待接取和进行中分栏，可升级同时接取数量和每日显示任务数量；列表显示 `[类型][D1] 任务简称`，进行中任务双行显示进度和剩余时间，右侧详情分区显示说明、奖励和失败惩罚。v1.16.20 起左右双列只允许一个真实选中；v1.16.46 起可免费开启自动交任务，每1游戏小时批量提交全部完成任务，交物品任务仍由服务端检查并移除真实物品。
- 任务追踪：独立小 UI，可关闭主界面后查看任务进度。
- 家园/传送：设置家、回家、返回出发点、删除出发点，临时传送点购买、覆盖、传送、返回。
- 系统升级：任务上限等系统能力升级。
- 天赋：可购买正面天赋、移除负面天赋，带风险说明。当前仍属于高风险功能。
- 属性：动态枚举原版和标准 `PerkFactory` MOD 技能，可按系统币金额购买 XP；“升到下一级”会先显示当前等级、目标等级、所需 XP 和费用，确认后复用服务端重新报价与同步路径。
- 车辆修复：商城车辆分类出售 5000 币的一次性系统车辆修复模块；持有后右键 4 米内车辆或当前乘坐车辆，完整修复标准车辆部件，不加油、不修改车内物品。
- 历史：记录重要操作；多人新记录使用结构化 code，客户端本地化显示。
- 银行：活期支持存取、支付、贷款还款和手动钱币整理；死亡只扣活期30%。v1.16.46 起可免费开启自动存款，每1游戏小时把全部随身系统币存入活期；新增稳健、平衡、激进三个汇总理财账户，按累计在线24游戏小时复利结算，首次日结后可部分或全部赎回到活期，死亡不扣理财。UI 不再创建新死期，旧死期存单继续按原规则支取。
- 说明：内置说明页面；记录/说明页使用单列文本布局，避免不需要的详情栏黑屏干扰。
- 多人轻同步：打开 UI 同步一次，关键操作后同步，后台每 5 分钟同步；切页不再请求服务器刷新，主要页面隐藏手动刷新按钮。
- 多人任务：交物品任务仍由服务端检查真实物品；击杀、移动、存活等非物品任务信任客户端进度后由服务端发奖励/扣惩罚。击杀任务使用 `task.killProgress` 独立累计，死亡重生后不再依赖角色总击杀数差值。死亡会让所有进行中任务失败；失败、超时、放弃的罚金先扣银行活期，不足再扣身上现金。
- 调试入口：连续点击“说明”页签 5 次会出现输入框，输入 `12130` 确认后发放 10000 系统币，单人/多人均可用于测试。
- 诊断页：显示 SP/MP、服务器 state、pending 命令、最后结果/错误、客户端与服务端命令计数，便于排查多人页面空白、提示缺失和同步问题。
- 本地化：标准 `Translate\CN/CH` 与 Lua fallback 覆盖并存；新增文案先写 `tools/godsystem_v11645_localization.yml`，再由生成器写入 Translate 和 ASCII-only Lua fallback。

当前设计分层：

- 前期消费：普通购买、单次传送。
- 前中期消费：腰包升级。
- 中后期消费：家园/传送点。
- 后期消费：天赋修改、分类抽奖解锁。

后续扩展原则：

- 先参考 `C:\Users\Admin\Desktop\PJ\File` 中同类 MOD 的代码和接口。
- 再按 GodSystem 当前分层实现。
- 新结论必须写回交接文档。

- v1.16.29 腰包与商店：系统腰包前戴/后戴都应被识别；“卖掉并上架选中”只回收系统腰包内选中物品，出售后解锁到商店；商店每页 20 件，上一页/下一页翻页，分类抽奖从分类菜单进入；购买/出售后尽量保持选中行和滚动位置。
- v1.16.31 管理页：入口仍在记录/说明旁边；单人默认可用，多人仅管理员/管理权限可用。配置列表显示中文名 + 英文内部键，详情页显示名称、内部键、类型、分组、范围、默认值、当前值和说明；物品覆盖详情提供 `Base.Axe|buy=500,sell=25,cat=weapon,shop=1,recycle=1,lottery=1` 示例。
# v1.16.52 单人菱形浮游机器人

- 单人左侧保留“同伴”页；多人完全隐藏，且不注册机器人更新、尸群扫描和绘制事件。
- 固定使用无实体的蓝色双层菱形浮游机器人，以 `renderline()` 直接绘制红色方向传感器和青色推进器；不再创建僵尸、读取机器人 PNG、复制外貌或切换形态。
- 提供蓝白照明、红色光束攻击、灵视和守护。普通攻击支持主动、防御和停火；灵视可标记当前楼层最近 50 只僵尸；守护在玩家 3 米内出现至少 1 只僵尸时击倒目标。
- 专属快捷栏固定三行，可切攻击模式、3/5/10 米跟随或原地守卫、发动灵视、切换守护、召回和显隐。
- 解锁、等级、共鸣、模式、快捷栏位置和剩余冷却保存在全局 ModData，跨死亡与退出保留；机器人坐标、光源、弹道和目标框只存在于当前运行会话。
- v1.16.53 新增五项顺序解锁且常驻叠加的攻击特效：脉冲震荡、能量灼蚀、弱点锁定、电弧连锁、过载爆裂。副目标伤害不递归触发特效；旧共鸣等级和加成保留，但后续共鸣购买要求功能满级且五项特效全部解锁。
