# v42.21_3.20.2：沙盒设置分组与翻译冲突修复

2026-09-29。以用户实机验收、已备份的 `42.21_3.20.1` 为基线。本版仅修正设置展示和 Workshop 文案维护；不改经济、任务或回收玩法，不覆盖已验收备份。

## 问题与证据

- 玩家截图中 `[任务]`、`[商城与回收]`、`[银行]` 重复四次。当前 GodSystem 中文 `Sandbox.json` 无重复前缀；本机同补丁 Project Babel 的 `Sandbox.json` 使用相同 `Sandbox_GodSystem_*` 键，并给部分键提供了四重前缀。70 个设置标签键重名，加载顺序可让其文本覆盖本 MOD。
- 本机 B42.21 原版服务器沙盒管理界面不读取选项的 `title` 分隔字段，100 项同处 `GodSystem` 页时无法显示预期分隔。原有 `title` 仍可用于新建游戏设置界面。
- 本地化生成器从既有英文生成文件取兜底文案，每次生成都会再加 `[Performance]`，造成英文标记累积。
- 仓库原 `workshop.txt` 与用户在 Workshop 测试目录手动维护的文案不同；直接从仓库覆盖会让用户重复修改。

## 修改

1. 所有沙盒选项仍使用 `GodSystem.<原配置名>`；`type`、`min`、`max`、`default` 与 3.20.1 完全一致。仅将展示翻译键改为独立的 `GodSystemSettings_<配置名>`，避开已确认的第三方同名翻译键。
2. 设置分为 7 个原生页面：装备、基础与任务、商城与回收、银行、水电与家园、角色成长、同伴与其他。页面内保留适用的次级分隔标题；只给可能影响性能的项目加一个 `[性能]` 标记。CN/CH/EN 同步生成。
3. 英文生成时先移除历史重复 `[Performance]`，再为性能项添加一次；重复运行不会继续叠加。
4. 仓库 `workshop.txt` 以测试目录已编辑的全文为底稿，只将第一行版本 `v42.21_3.20.1` 更新为 `v42.21_3.20.2`。今后处理版本前须先核对用户在测试目录中维护的说明，不用旧仓库文案覆盖。
5. 两处 `mod.info`、运行版本和经济策略版本同步为 `42.21_3.20.2`。经济策略版本字段沿用项目统一版本规范；本版没有改变定价逻辑。

- 新生成的 GodSystem 中文翻译键与本机 Project Babel 中文 `Sandbox.json` 的键交集为零。CN、CH、EN 连续重新生成结果稳定；保留用户 Workshop 文案 7476 字节，版本行之外逐字节相同。
- `python tools/tests/run_lua_tests.py`：140 个打包 Lua 文件通过 Lua 5.1 编译，行为回归通过。
- `python tools/tests/run_kahlua_tests.py --game "D:\SteamLibrary\steamapps\common\ProjectZomboid"`：B42.21 Kahlua 回归通过。

- 已同步 Workshop 测试副本，源码与测试目录 605 个非临时文件 SHA-256 全部一致；在测试目录运行完整静态检查并复用开发目录已安装的 LuaLS 工具，通过。
