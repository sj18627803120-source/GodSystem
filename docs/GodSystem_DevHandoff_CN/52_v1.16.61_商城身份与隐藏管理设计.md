# GodSystem v1.16.61 商城身份与隐藏管理设计

## 目标

本版只修复商城及上架链路：统一普通物品与家具变体身份，消除内置商品和回收解锁商品的重复记录，并把玩家主动删除解锁商品改为可恢复的隐藏状态。

目标游戏版本仍为 Project Zomboid Build 42.19。人物负重、空间终端、压缩、机器人、任务和经济数值保持 v1.16.60 行为不变。

## 已确认规则

- 普通商品身份使用 `fullType`；家具身份使用 `fullType + worldSprite`。
- 内置商城单品默认视为已经上架，不能再次付费上架。
- 玩家上架记录保存在 `unlockedShopItems[variantKey]`，新增 `hidden` 布尔字段；旧记录默认为未隐藏。
- 玩家操作不再删除已经提交的上架记录；隐藏与解除隐藏均免费。
- 隐藏只管理玩家自己上架的商品，内置商城商品不进入隐藏管理。
- 多人隐藏状态按玩家账户独立保存，互不影响。
- 隐藏商品不出现在直接购买列表，但仍保留在抽奖候选中。
- 旧 `removeUnlocked` 多人命令只作为兼容入口保留，行为改为隐藏，不能再删除记录。

## 数据与交易边界

- 所有上架入口必须使用同一“是否已经上架”判断，同时检查内置单品键和玩家上架键。
- 上架多人请求必须携带精确物品实例 ID；服务端重新核验真实实例、所有权、`fullType` 和 `worldSprite`。
- 家具购买继续通过实例工厂创建，并在扣费前验证恢复后的世界贴图；创建或核验失败时回滚已发放物品且不扣币。
- 旧存档中的内置商品重复解锁记录在迁移时合并；相同家具变体合并，不同 `worldSprite` 继续分别保留。
- 事务回滚可以移除本次尚未提交的新记录，但任何已提交记录都只能隐藏，不能由玩家删除。

## 界面与性能

- 商城主界面的“删除解锁”改为“隐藏解锁”，右键菜单增加隐藏入口。
- 新增隐藏管理弹窗，只读取已经同步到本地的玩家上架记录，支持分类、状态和文本筛选，以及加入隐藏和移出隐藏。
- 商城和隐藏弹窗只在页面打开、筛选变化、搜索变化或状态同步后重建；不注册逐帧、分钟级背包或商城扫描。

## 发布门槛

- 新增 v1.16.61 静态与 Lua 行为测试，并运行 v1.16.60 至 v1.16.53 的现有回归、编码检查及 Lua 5.1 编译。
- B42.19 实机必须覆盖绷带重复、沙滩椅、床两组件、铁架和大型金属货架，以及 SP 读档和 MP 双玩家隔离。
