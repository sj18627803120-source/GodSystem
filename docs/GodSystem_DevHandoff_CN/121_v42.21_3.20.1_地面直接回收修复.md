# v42.21_3.20.1：地面直接回收修复

2026-09-29 用户反馈当前版本测试通过，并要求更新唯一滚动备份；未逐项确认的多人场景不据此单独标记通过。

## 状态与证据

- 目标游戏：本机 Project Zomboid B42.21.0；源码与测试副本目标版本 `42.21_3.20.1`。
- 用户在 3.20 实机中选择地面物品回收，出现“选中物品已经变化，本次操作已取消”。该提示来自 GodSystem 的来源复核。发生时的本机 `console.txt` 未见对应 Lua 异常；旧会话的 Java 桥空指针堆栈不是本次提示的直接证据。
- 代码确认两处误判：玩家小数坐标与目标整数格直接比较会把相邻格判为超距；散落物已经由真实世界对象定位后，仍可能要求临时 `floor` 容器包含它。B42.21 原版 `ISGrabItemAction` 在拾取散落物时验证世界对象，移除时调用 `removeFromWorld`、`removeFromSquare`，不要求 `floor:contains(item)`。

## 修改

1. 以玩家所在格与目标格比较相邻距离，保留同楼层、阻挡、安全屋、来源身份等核验。
2. `worldItem` 以同格世界对象和物品 ID 为权威定位；地面临时容器不参与存在性或删除许可判断。世界容器、尸体、车辆与嵌套背包继续保留原容器检查。
3. 散落物移除沿用原版世界对象路径；事务失败仍通过原有回滚重新放回地面。MP 重复请求仍由操作回执保护。
4. 来源定位失败时按现有汇总诊断格式记录 `distance`、`access`、`changed` 等原因码，避免下次只剩同一句 UI 提示。没有记录物品清单。
5. 两处 `mod.info`、运行版本、经济策略版本和 `workshop.txt` 首行统一为 `42.21_3.20.1`。
