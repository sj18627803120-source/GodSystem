## v1.16.0 单入口 SP/MP 专项测试

- 只启用 GodSystem 一个 MOD 能进入单人游戏，原 v1.15.6 单机功能不退化。
- Workshop 上传目录第一层仍是 `workshop.txt`、`preview.png`、`Contents`，且 `Contents\mods` 下只有 `GodSystem`。

单人回归：
- 新角色初始系统币、商城购买、回收、腰包领取/升级/自动回收、任务、传送、删除出发点、天赋修改均按 v1.15.6 行为正常。
- 单人存档数据仍使用 `GodSystem_CN_Data`，不被多人 `GodSystem_CN_Data_MP` 影响。

多人基础连接：
- Dedicated/Host MP 启用同一个 `GodSystem_CN` 后，客户端打开 UI 能收到服务器 state，余额显示与背包实体系统币一致。
- 刚进服务器时 `hello` 握手能自动重试；如果第一次玩家对象未就绪，稍后打开 UI 仍能收到服务器 state。
- 服务端任一命令报错时，客户端收到错误提示且 UI 能刷新，不应导致后续按钮全部失效。
- 打开 UI 后在商城、回收、腰包、任务、家园、历史之间快速切换，页面内容不应变空；切页不应触发服务器刷新。
- 刚进多人服务器马上打开 UI 时，如果服务器 state 未返回，应显示“正在同步服务器数据”，随后自动刷新出真实内容。
- 快速切页、缩放窗口、关闭再打开后，商店、回收、腰包、任务、历史页面不应永久空白；最多短暂显示同步提示。
- 单人和多人快速切换“记录/说明”页、缩放窗口、关闭重开后，记录/说明应保持单列文本显示，不应出现整块黑页或内容丢失。
- 多人记录页中新产生的购买、回收、腰包、任务、家园、天赋、击杀奖励记录应显示中文，不应继续出现乱码；旧存档已存在的乱码记录可暂不清理。
- 多人击杀僵尸后，除了发放实体系统币和刷新 UI，还应出现头顶提示“击杀僵尸 +X 系统币”。
- 多人购买/回收/腰包一键出售/任务接取后，不应先闪成空列表再恢复；应等待服务器 state 回包刷新。
- 商城、回收、天赋、升级、家园和同步占位页不应显示普通手动刷新按钮；任务付费刷新按钮仍应保留。
- 每 5 分钟现实时间后台同步一次；如果同时发生关键操作，应先处理关键操作，再处理后台同步。
- 击杀奖励达到 10 击杀或打开 UI/后台同步时应结算；少量击杀不用每 3 秒刷新服务器。
