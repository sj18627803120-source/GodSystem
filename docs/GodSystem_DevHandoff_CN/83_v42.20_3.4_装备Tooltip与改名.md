# v42.20_3.4 装备 Tooltip 与改名

日期：2026-09-08。开发分支：`codex/42.20_3.4`。开发版本：`42.20_3.4`。未发布、未上传、未创建备份。

## 已实现

- 绑定武器 Tooltip 通过链式 `ISToolTipInv.render` 追加全部当前已支持强化：伤害、耐磨、近战攻速、枪械精准、后坐力延迟及近战冻结；普通物品直接走原渲染。属性行从共享装备属性注册表生成，后续新增属性只需接入该注册表、支持判断与翻译，不再改 Tooltip 主渲染逻辑。追加逻辑被保护，异常时只跳过本次 GodSystem 内容。
- MP Tooltip 使用只读 `equipmentInspect`／`equipmentProjection`，以世界、装备 UUID、代次、物品 ID、类型和修订号核对权威档案；客户端缓存最多 128 项并限流，悬停不扫描库存。
- 装备页新增“修改名称”窗口。名称最多 30 个 Unicode BMP 码点，自动去首尾普通／不换行空格，拒绝控制字符、无效 UTF-8 和 Emoji。B42 `ISTextEntryBox` 在部分 Kahlua 路径返回 `java.lang.String` userdata，校验器会安全转换该输入，而不会把任意表或数值对象放行。
- 改名是零费用装备事务，复用操作 ID、回执、物品快照和回滚。改名、恢复默认名、找回继承自定义名均由权威端写入真实物品并同步原生字段。
- 3.3 档案没有 `customName` 时按未自定义处理；解绑保留实体名称；旧代实体只保留原生名称，不恢复装备身份。
