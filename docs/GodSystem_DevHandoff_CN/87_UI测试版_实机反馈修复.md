## 用户现象与根因

1. 任务、商城、武器强化和操作记录中中文不见，只留下数字。`TerminalDesign.wrap` 的 UTF-8 字节匹配式在 Kahlua 的 UTF-16 字符串上过滤掉中文。`UISafety.fitText` 也误把中文码元当成 4 字节字符。现在使用检测编译器字符串语义的字符边界函数，保留 BMP 中文、Unicode 标点和完整代理对；换行保留段落和空行。
2. “伴随灵”统一改为“机械同伴”。修改权威 YAML、UI 导入种子、手册源与预览源，重新生成 CN／CH JSON、TXT 和 Lua fallback；内部 `companion` ID 不变。
3. 用户错误栈：`GodSystem_EquipmentCombat.lua:23 -> ImpactRuntime.consider/step/tick -> OnTick`，`Object tried to call nil`。同补丁 `IsoZombie.class` 的公开方法为 `isCrawling()Z`、`knockDown(Z)V`，没有 `isCrawler`；原版 `media/lua/client/DebugUIs/DebugContextMenu.lua` 第 551 行使用 `isCrawling()`、第 668 行调用 `knockDown(hitFromBehind)`。`isKnockedDown` 来自 `IsoGameCharacter`，`isOnFloor/getCurrentSquare` 来自 `IsoMovingObject`。
4. 冲击消费蓄力后没有作用：上述非法调用中断延迟扫描。此外扫描仅在拥有对象列表时才移动坐标，未加载格子会造成无限重复；队列用稀疏表长度寻址，也可能丢失后来排队的冲击。现改为每格必定前进、显式 head/tail、命中点坐标快照和执行前目标复核。使用原版真实击倒调用，删除未经实机验证的状态标志替代分支；调用异常保留诊断信息并计入失败数。
5. 同一编码差异会拒绝中文装备改名。共享名称验证新增 Kahlua UTF-16 分支，保留原有 BMP／30 字／控制字符限制。
