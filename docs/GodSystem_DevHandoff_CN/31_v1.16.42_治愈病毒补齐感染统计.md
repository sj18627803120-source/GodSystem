# v1.16.42 治愈病毒补齐感染统计

## 背景

用户确认生化疫苗来源于参考 MOD：

`C:\APP\Steam\steamapps\workshop\content\108600\3388468313\mods\RaccoonCityB42`

该 MOD 的 `Base.BiochemicalVaccines` 不是原版物品，而是 RaccoonCityB42 自定义物品。其治愈逻辑在客户端 `BiochemicalVaccinesMenu.lua` 和服务端 `RaccoonCityServerCommand.lua` 中都执行同一组感染清理。

## 参考逻辑

RaccoonCityB42 的疫苗治愈核心行为：

- 遍历 `bodyDamage:getBodyParts()`，对每个部位执行 `bodyPart:SetInfected(false)`。
- 执行 `bodyDamage:setInfected(false)`。
- 执行 `player:getStats():set(CharacterStat.ZOMBIE_INFECTION, 0)`。
- 执行 `bodyDamage:setInfectionTime(-1.0)`。
- 执行 `bodyDamage:setInfectionMortalityDuration(-1.0)`。

其中 `CharacterStat.ZOMBIE_INFECTION` 是 v1.16.41 治愈病毒路径中缺失的关键清理点。

## 本次实现

GodSystem v1.16.42 在治愈病毒路径中补齐：

```lua
player:getStats():set(CharacterStat.ZOMBIE_INFECTION, 0)
```

实际实现带有 `CharacterStat` 存在性检查和 `pcall` 包裹，避免不同环境缺少该枚举时直接红字。该逻辑已同时加入：

- 单人/客户端本地路径：`GodSystem_Core.lua` 的 `gsMedicalClearInfection(body, targetPlayer)`。
- 多人服务端路径：`GodSystem_Server.lua` 的 `medicalClearInfection(body, player)`。

保留 v1.16.41 的安全边界：

- 不恢复“压制病毒”。
- 不使用 `setInfectionTime(0)`。
- 不重新加入 `MedicalSuppressInfectionCost` 或 `suppressInfection`。
