# v1.16.41 废弃压制病毒

## 背景

用户实测 v1.16.40 的“压制病毒”会瞬间暴毙，表现像感染进度直接满了并触发死亡。

v1.16.40 的压制实现是：

```lua
setInfectionTime(0)
setInfectionLevel(0)
```

并且不执行：

```lua
setInfected(false)
```

实测结论：在 B42.19 里，感染标记仍为 true 时写 `setInfectionTime(0)` 不安全，可能被游戏当作感染倒计时到点或触发结算。后续不要再用该方案做“压制”。

## 处理方式

v1.16.41 直接废弃压制功能：

- 从 `MEDICAL_SERVICE_ORDER` 移除 `suppressInfection`。
- 从客户端 `GodSystem.getMedicalServiceInfo()`、`applyMedicalServiceLocally()`、`performMedicalService()` 移除压制分支。
- 从服务端 `medicalServiceInfo()`、`medicalApply()`、`medicalNotifyMessage()`、未感染预检查移除压制分支。
- 从配置和管理员菜单移除 `MedicalSuppressInfectionCost`。
- 从 active CN/CH/Override 本地化移除压制服务、按钮、通知、管理员设置文本。

旧客户端或异常命令如果还发送 `suppressInfection`，服务端拿不到 serviceInfo，会直接失败，不会写入玩家身体状态。

## 当前医疗服务

保留：

- 感染检查：只读检测，不改身体状态。
- 治疗伤势：治疗普通伤势，不治愈僵尸病毒。
- 治愈病毒：价格 2000，真正清除感染。

治愈病毒当前逻辑：

```lua
body:setInfectionTime(-1.0)
body:setInfectionLevel(0)
body:setInfected(false)
body:setIsFakeInfected(false)
body:setInfectionMortalityDuration(-1.0)
```

并遍历 body part 清：

```lua
part:SetInfected(false)
part:SetFakeInfected(false)
part:setInfectedWound(false)
part:setWoundInfectionLevel(-1)
```

## 疫苗物品来源结论

用户给的参考 mod：

`C:\APP\Steam\steamapps\workshop\content\108600\3711250417\mods`

搜索结果：

- 原版 `C:\APP\Steam\steamapps\common\ProjectZomboid` 未找到 `BiochemicalVaccines` 物品脚本定义。
- 参考 mod 只在 `MySpatialRefuge_Shop\common\media\lua\shared\MSR_ShopData.lua` 中引用 `{type = "Base.BiochemicalVaccines", count = 1}`。
- 该参考 mod 内没有定义 `Base.BiochemicalVaccines` 的脚本，也没有对应治疗 Lua。

结论：`Base.BiochemicalVaccines` 不是可确认的原版物品，也不是这个参考商店 mod 自己实现的疫苗逻辑。它更可能来自其他 MOD、依赖、作者环境里的预留物品，不能作为 GodSystem 的治疗接口依据。
