# v1.16.49 幽灵投影同伴实现记录

## 范围

- 仅支持单人。多人客户端和服务端不注册同伴运行、扫描、绘制、协议或持久化处理。
- 新增淡金色人形投影和低开销金色光团，提供照明、普通攻击、灵视、守护、长期升级和无限共鸣。

## 代码入口

- `shared/GodSystem_CompanionConfig.lua`：数值表、价格倍率、默认数据和等级校正。
- `client/GodSystem_Companion.lua`：投影外壳、光源、攻击、灵视、守护、生命周期、绘制和能力页数据。
- `client/GodSystem_CompanionUI.lua`：固定三行专属快捷栏。
- `client/GodSystem_Core.lua`：持久化初始化和统一购买，支付复用 `GodSystem.spendCurrency()`，顺序为活期后现金。
- `client/GodSystem_UI.lua`：单人导航、能力列表、五按钮动作栏和多人管理项过滤。

## 关键实现

- 人形参考本地 B42.19 `KnoxSurvivors`：`addZombiesInOutfit()`、编号 Naked outfit、行为压制、外貌 `ItemVisual` 重建。附近没有空闲格时自动改为光团。
- 光源使用 `IsoLightSource`，只在格子或半径变化时重建；乘车、隐藏、退出和异常重建时清理。
- 普通攻击搜索间隔 0.2 秒，弹道飞行 0.2 秒。灵视只在手动发动时扫描，守护冷却期间不扫描，触发检测固定 7x7 格。
- 致死流程为 `setAttackedBy(player)`、扣血、`Kill(player)`，只在原版击杀数没有增长时补到旧值加一。
- 同伴数据位于全局 `data.companion`；实体、光源、弹道和灵视目标不序列化。

## 实机必测风险

- 僵尸外壳在其他行为/恐慌/NPC MOD 同时启用时的表现只能进游戏确认。出现任何外壳异常时先切光团，并记录控制台日志。
- 人形动画、投影透明度、衣物外观、跨楼层重建、动态光源残留、击杀归属和不同缩放下四角框必须实机验证。
