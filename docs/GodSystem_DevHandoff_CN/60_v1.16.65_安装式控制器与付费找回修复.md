# v1.16.65 安装式控制器与付费找回修复

## 问题与结论

v1.16.64 把系统仓库控制器作为普通物品放到地面。B42.19 实机反馈确认：

- 放到地上没有反应，右键没有 GodSystem 操作。
- “领取控制器”可以反复点击，生成大量控制器并重叠在同一位置。

本版不改仓库连接、索引、筛选和真实物品存取方案，只替换控制器的领取、安装、收回与找回生命周期。实现参考当前原版车载电池充电器的固定对象流程：同一个物品实例从背包转为 `IsoCarBatteryCharger` 世界对象，收回时再把该实例放回背包。控制器不是充电器功能，GodSystem 会移除其原版充电右键入口。

## 安装与收回

1. 玩家领取后获得一个控制器安装包。
2. 背包右键安装包，选择“安装系统仓库控制器”。
3. 进入单格光标：有效位置显示蓝色，无效位置显示红色。
4. SP 直接复验；MP 由服务端复验精确物品 ID、网络 ID、控制器令牌、玩家权限、距离、楼层、地面和同格重叠。
5. 验证通过后创建固定世界对象，再移除背包中的精确安装包。若移除失败，立即撤销世界对象。
6. 安装后右键设备可打开仓库或收回。收回先把同一物品实例加入背包，再移除世界对象；移除失败则撤销背包发放。

控制器固定对象保存 `networkId`、`controllerToken`、`controllerItemId` 和 `controllerObjectId`。普通物品栏、普通地面物品和同坐标的其他对象不能冒充有效控制器。

## 领取与2000币找回

- 每套网络第一次领取免费。
- 当前玩家背包已有有效安装包时拒绝再次领取。
- 控制器已经安装时，领取页不再提供免费领取，只显示“强制找回（2000）”。
- 控制器遗失时显示“找回控制器（2000）”。
- 成功找回会轮换令牌，因此远处未加载的旧控制器即使之后出现，也只能显示为失效外壳，不能再打开旧网络。
- 找回只清理当前玩家背包中同一网络的旧副本，以及当前已加载、且身份与持久记录精确匹配的旧安装对象；不扫描全地图，也不删除其他玩家或其他网络的控制器。
- 费用使用现有“银行活期优先，不足再扣随身系统币”的统一支付路径。扣费失败不生成新包；提交失败会退款。

`controllerClaimedOnce`、`controllerState`、`controllerItemId` 和安装坐标保存到系统仓库全局 ModData。领取、安装和收回都携带操作 ID 与请求指纹；网络重试只回放原结果，不能重复扣费、重复安装或复制物品。

## 旧存档迁移

- v1.16.64 已在背包中的有效控制器视为现有安装包，可以直接安装，不强制收费。
- 持久记录指向普通地面物品时显示旧版地面状态；玩家可先捡回并安装，也可以花2000强制找回。
- 没有 `controllerClaimedOnce` 的旧网络，会根据现有控制器令牌、坐标和物品状态推导是否已经领取，避免旧玩家重新获得无限免费领取。
- 同网络旧副本不会仅凭 `fullType` 删除，必须同时匹配网络与令牌；其他网络和无关物品不受影响。
