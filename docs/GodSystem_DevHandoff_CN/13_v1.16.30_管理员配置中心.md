# v1.16.30 管理员配置中心

## 目标

本版本放弃原计划的 `sandbox-options.txt` 沙盒菜单，改为 GodSystem 自己的运行时管理员配置中心。

入口放在主 UI 顶部工具按钮区，靠近“记录 / 说明 / 诊断”。单人默认可用；多人由服务器下发 `admin=true` 后显示，服务端同时对所有写入命令做权限校验。

## 数据分层

最终配置读取顺序：

1. `GodSystem_Config.lua` 和 `GodSystem_Prices.lua` 默认值。
2. `GodSystemConfig.ItemOverrides` 文件预设覆盖，当前版本保留接口。
3. 运行时管理员设置和物品覆盖。

多人运行时配置保存到服务器 ModData：

- Key: `(GodSystemConfig.DataKey .. "_MP_AdminConfig")`
- 字段：`settings`、`itemOverrides`

单人运行时配置保存到玩家本地 GodSystem ModData：

- `data.adminConfig.settings`
- `data.adminConfig.itemOverrides`

## 关键文件

- `shared/GodSystem_AdminConfig.lua`
  - 默认设置元数据。
  - 设置清洗和物品覆盖清洗。
  - `applyRuntime()` 统一应用运行时配置。
  - 价格、回收、抽奖、任务奖励/惩罚倍率辅助函数。
- `server/GodSystem_Server.lua`
  - 服务器保存管理员配置。
  - `adminConfigGet/adminConfigSet/adminItemOverrideSet/adminItemOverrideClear`。
  - 多人关键结算按服务器运行时配置执行。
- `client/GodSystem_Core.lua`
  - 单人本地保存配置。
  - 多人接收服务器快照后应用到 UI 预览。
- `client/GodSystem_UI.lua`
  - 新增 `admin` 页。
  - 支持编辑全局设置和单物品覆盖。

## 第一版管理员页范围

全局设置：

- 初始点数、击杀奖励。
- 每日任务数、最大进行中任务、刷新任务费用、任务限时。
- 家园/临时传送/天赋/腰包自动回收等基础费用。
- 商城买价倍率、回收卖价倍率、任务奖励倍率、任务失败惩罚倍率。
- 多人后台同步间隔。
- 商店、回收、银行、传送、天赋、腰包自动回收、分类抽奖、任务系统开关。

物品覆盖：

- 买价 `buy`
- 卖价 `sell`
- 分类 `cat`
- 是否可购买 `shop`
- 是否可回收 `recycle`
- 是否可抽奖 `lottery`

管理员弹窗输入格式：

```text
Base.Axe|buy=500,sell=25,cat=weapon,shop=1,recycle=1,lottery=1
```

## 后续注意

- 运行时配置不是原生沙盒配置，不在世界创建界面显示。
- 多人必须以服务器配置为准，客户端 UI 只显示服务器快照。
- 以后如果做导入/导出，应基于 `GodSystem_AdminConfig.buildSnapshot()`，不要重新发明一套格式。
- 管理员 UI 暂时不做复杂表格/批量编辑，避免引入新的滚动黑屏和选择状态问题。
