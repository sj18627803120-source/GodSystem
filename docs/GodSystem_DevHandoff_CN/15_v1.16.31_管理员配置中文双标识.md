# v1.16.31 管理员配置中文双标识

## 目标

v1.16.30 的管理员配置中心功能已经落地，但页面中大量显示英文内部 key，服主不容易判断每一项的实际含义。v1.16.31 不改变管理员权限、保存路径、服务器同步和物品覆盖输入格式，只增强显示与说明。

## 实现内容

- `GodSystem_AdminConfig.lua` 的每条 `SETTING_META` 新增 `labelKey` 和 `descKey`。这些字段会跟随 `buildSnapshot()` 下发，所以单人和多人 UI 使用同一套显示元数据。
- 管理页列表显示格式改为 `[分组中文] 中文名 (英文内部键) = 当前值`。示例：`[基础] 初始系统币 (StartingPoints) = 60`。
- 配置详情页改为分行显示：名称、内部键、类型、分组、范围、默认值、当前值、说明。
- 管理页搜索范围扩展到中文显示名、中文说明、中文分组名、英文 key、类型、物品 fullType 和详情文本。
- 单物品覆盖详情加入填写示例和字段说明，继续使用：

```text
Base.Axe|buy=500,sell=25,cat=weapon,shop=1,recycle=1,lottery=1
```

## 单人/多人影响

- 单人：仍然保存到玩家本地 GodSystem ModData，编辑后本地立即 `applyRuntime()`。
- 多人：仍然由服务器保存管理员配置并下发 snapshot；客户端只展示服务器快照，写入命令仍由服务端校验权限。
- 本次没有修改买卖、回收、任务、传送、天赋、银行等结算逻辑。

## 后续注意

- 新增管理员配置项时，必须同时加 `labelKey`、`descKey` 和 `GodSystem_Localization_Override.lua` fallback 文本。
- 管理页中文 fallback 继续用 UTF-8 byte escape，避免 PowerShell 控制台编码影响 Lua 文件。
