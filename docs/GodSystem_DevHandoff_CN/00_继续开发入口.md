## 当前关键结论

- v1.16.53 属性枚举使用 `Perks.getMaxIndex()` / `Perks.fromIndex()` 找技能枚举值，但名称、父类和累计等级 XP 优先从 `PerkFactory.getPerk(perk)` 返回的注册技能对象读取。MP 由服务端重新报价、按活期后现金扣款，使用无倍率 `AddXP(perk, amount, false, false, false, false)` 后再调用 `SyncXp()`；失败按原资金来源退款。
- v1.16.53 整车修复沿用原版 B42.19 `vehicle:repair()`，通过 `vehicle:getId()` / `getVehicleById()` 定位。必须先验证模块、车辆、楼层和 4 米距离，先移除模块再修复复查，失败返还新模块。
- B42.19 自定义可穿戴容器至少要同时声明 `BodyLocation`、`CanBeEquipped` 并注册同一个命名空间位置，但静态定义齐全仍不代表目标补丁可用。v1.16.54 实机仍失败，当前终端已改用原版 `base:necklace` 并删除自定义注册文件。
- B42.19 直接对 GodSystem 终端调用 `setCapacity()` 仍只允许安全值49。v1.16.62 的49以上容量是实验性窄范围方法包装，不写入原生大容量字段；最高1999来自旧 B42 参考 Mod 的2000边界，必须通过 B42.19 SP/MP 实机后才能认为可用。
- 用户确认某版本已发布后，下一版才把它作为兼容基线。未发布测试版本默认可以删除过时物品、字段和迁移逻辑；本地测试确认前只保留本地 Git 分支和提交，不推送 GitHub。
- `GodSystem_Server.lua` 已接近 Lua 5.1 单 chunk 的 200 个顶层 local 上限。新增服务器 helper 应优先挂到 `GodSystemServer` 命名空间或拆分模块；每版必须对全部 Lua 执行 `C:\Users\Admin\Tools\Lua51\luac.exe -p`。
- v1.16.48 隐藏旧回收页但保留底层兼容代码；新交易入口是原版库存右键。SP/MP 都必须按 `item:getID()` 精确定位，外部容器物品先通过原版转移动作进入玩家库存，删除后确认物品确实离开容器，最后才发币或写上架状态。
- v1.16.48 多人理财不再依赖服务端 `OnPlayerUpdate`。客户端只累计本次在线会话的世界小时并发送正整数小时，服务端累计到 24 小时后结算；断线重进不补离线时间。
- v1.16.48 的 64 项沙盒配置只在 SP 角色或 MP 服务端还没有持久 `settings` 时导入。进入世界后仍以系统管理页为运行时权威，旧存档绝不能被沙盒值覆盖。
- v1.16.46 新增自动存款、自动交任务和三个风险理财账户。SP 本地结算，MP 资金/物品/理财由服务端结算；自动操作顺序固定为腰包回收、任务领取、现金存款。理财只累计在线游戏时间，首次日结前不可赎回，死亡不扣理财余额。
- v1.16.42 当前修复：治愈病毒在清 BodyDamage、感染时间、死亡时间和身体部位感染之外，还会清 `player:getStats():set(CharacterStat.ZOMBIE_INFECTION, 0)`；该逻辑参考同版本 RaccoonCityB42 的 `Base.BiochemicalVaccines` 生化疫苗。
- v1.16.44 修复：银行借贷 UI 乱码来自 v1.16.43 新增文本的本地化层问题。修复点是补齐 `Translate\CN/CH\IG_UI_*.txt` 借贷表项行尾逗号，并把 `GodSystem_Localization_Override.lua` 中借贷与管理员借贷配置 fallback 改为 ASCII-only 的 UTF-8 字节转义。新增专项测试 `Test-GodSystemV11644.ps1`。
- v1.16.43 已实现银行借贷系统，见 `32_v1.16.43_银行借贷系统技术方案.md`、`33_v1.16.43_银行借贷系统实施计划.md`、`34_v1.16.43_银行借贷系统实现.md`。已确认并实现：首版单笔贷款、还款只扣活期、信用破产不清死期、玩家死亡不清空欠款；破产用 `loanCreditSpentOffset` 重置成长额度，不直接重置 `data.stats.spentPoints`。
- v1.16.41 修复：医疗服务中“压制病毒”已废弃并从 UI、配置、SP/MP 服务分支和本地化移除。不要再使用 `setInfectionTime(0)` 这类压制方案；用户实测会瞬间暴毙。
- v1.16.40 结论保留：治愈病毒价格 2000，需要同时清 `BodyDamage:setInfected(false)`、`setIsFakeInfected(false)`、感染进度、死亡时长，以及每个 body part 的 `SetInfected(false)` / `SetFakeInfected(false)` / `setInfectedWound(false)` / `setWoundInfectionLevel(-1)`。
- v1.16.39 上一版新增：回收页右键“仅上架”，费用为商城购买价 50% 且最低 50，只解锁商城购买，不删除物品；多人由服务端验证真实物品和余额。
