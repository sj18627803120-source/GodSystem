## 当前架构边界

- `shared` 保存规则、schema、协议、确定性计算与双方安全 helper。
- `client` 负责 UI、选择快照、展示缓存、SP 适配和 MP 请求桥。
- `server` 负责 MP 权威存档、真实对象定位、验证、事务与命令路由。
- 装备身份使用世界 ID、装备 UUID、代次、原生物品 ID 与有效槽位关系共同确认；物品 ModData 只是定位信息。
- 普通右键、Tooltip 和绘制路径不扫描全背包、不重新报价、不逐帧请求服务端。
- 付费/破坏性操作遵循：验证 → 意图/快照 → 扣费 → 修改 → 核验 → 提交 → 同步；失败按真实来源回滚。
- 功能关闭时隐藏对应入口，同时保留服务端权限检查。
