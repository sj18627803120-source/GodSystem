## 本轮实现

### 系统面板快捷键

- 新增 `GodSystem_Keybind.lua`，通过 B42 的 `PZAPI.ModOptions` 注册面板快捷键，默认值为 `N`。
- “快捷”页面可捕获下一次按键、恢复默认、禁用快捷键并显示当前设置。
- `Esc` 只取消捕获；聊天框、文本输入、确认弹窗以及没有有效玩家时不会触发主面板。
- 系统内修改与原版 Mod Options 使用同一个绑定值；发现冲突时只提示，不覆盖其他绑定。

### 任务纵向模块

- 新增 `GodSystem_TaskService.lua`，集中负责任务生成、刷新、排序、接取、进度、领取、失败、放弃、超时和死亡结算。
- `GodSystem_Core.lua` 与 `GodSystem_Server.lua` 保留薄适配入口，SP/MP 调用同一套任务规则，不再各自维护一份完整任务实现。
- 旧 `data.tasks`、任务 ID、状态和进度继续使用，42.20.1.7 存档不需要重置。
- 新增长期许可任务“完成 50 个其他任务”：唯一存在、不占每日生成数、接取后占任务槽、无时限，只统计接取后成功领取奖励的其他任务；领取、失败或放弃后会补回新的待接任务。
- 奖励为真实可交易物品 `GodSystem.StorageExpansionPermit`。许可任务主动放弃或死亡失败时，按“活期优先、随身系统币其次”扣除合计余额的 50%；该死亡惩罚替代原活期 30%，普通任务罚金仍单独结算。
- 死亡结算使用保存于玩家 ModData 的死亡令牌防重复；重生时才清除令牌。

### 个人分类仓

- 新增独立账户数据 `personalStorage`。13 个分类各自从 0 容量开始，使用许可后所选分类永久增加 200；通用容量每次固定花费 10000 系统币增加 10。
- 通用占用按 `Σ max(0, 分类已用 - 分类专属容量)` 计算，不与实体仓重量容量混用。
- 个人仓完全私有并可远程打开；实体网络仓继续保存真实物品、共享权限和原有核心规则，两者互不替代。
- 存入时将真实实例转换为版本化 Lua 快照并移除原物品，取出时根据快照重建新实例。新实例 ID 会变化，其他 Mod 对旧实例 ID 的引用不保证保留。
- 快照覆盖基础属性、食物、液体、武器与附件、服装、钥匙、书籍、媒体、地图、家具贴图、嵌套容器和 Lua 安全 ModData；最多递归 32 层并防止循环。
- Java userdata、函数、线程、循环表和未知状态会被省略并标记“简化保存”；无法建立基础快照的物品不会删除；缺少物品定义的快照会继续保留。
- 非空嵌套容器按整棵树计数并原子处理，容量不足时整件跳过，不拆散内部物品。
- 远程窗口支持来源切换、分类、状态、搜索、排序、Ctrl/Shift 多选、存入、取出和批量结果统计。

### 实体仓转换桥

- 新增 `GodSystem_StorageBridge.lua`，是唯一同时接触个人仓与实体仓接口的集成模块。
- 实体仓管理器只暴露“检查网络物品、验证并提取、路由并加入”三个窄接口；个人仓不读取实体仓内部表。
- 实体转个人由服务端复验真实物品和个人容量；个人转实体先重建实例，再交给现有容器角色和优先级路由。
- 没有合法实体落点时保留虚拟快照，不产生地面副本。单批最多处理 250 件，网络重试按操作 ID 返回已缓存结果。

## 模块边界

```text
GodSystem_UI / GodSystem_StorageUI
├─ GodSystem_Keybind
├─ GodSystem_PersonalStorageUI
└─ 现有实体仓 UI

GodSystem_Core / GodSystem_Server（薄适配入口）
├─ GodSystem_TaskService
├─ GodSystem_PersonalStorageClient / Server
│  ├─ GodSystem_PersonalStorage（容量与事务）
│  └─ GodSystem_ItemSnapshot（物品快照）
└─ GodSystem_StorageBridge
   ├─ 个人仓窄接口
   └─ GodSystem_StorageManager 三个实体仓窄接口
```

新领域模块不 `require` Core、主 UI 或主 Server；UI 不直接写任务与个人仓存档；个人仓和实体仓只经转换桥组合。商城、银行、终端、机器人等稳定模块本轮没有重构。

## 实机重点风险

- `PZAPI.ModOptions` 在实际游戏中修改、保存、重载和冲突提示的表现。
- 不同原版与第三方物品的状态读写接口可能不是完全对称；简化保存提示必须先于真实删除出现。
- 武器附件、液体、服装补丁、家具贴图及深层嵌套容器必须做实际往返核对。
- MP 私有账户切片、断线重试、两人共用实体仓转换和服务端重启必须确认不复制、不丢失。
- 许可任务的死亡 50% 与普通任务罚金需要通过一次真实死亡核对账目。
