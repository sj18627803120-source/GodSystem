## 当前稳定打包命令

从用户实测成功目录重新生成稳定 zip：

```powershell
$source = 'C:\Users\Admin\Zomboid\Workshop\GodSystem'
$dest = 'C:\Users\Admin\Desktop\PJ\GodSystem_v1.15.3_B42_WorkshopUpload.zip'
$temp = 'C:\Users\Admin\Desktop\PJ\GodSystem_v1.15.3_B42_WorkshopUpload.tmp.zip'
if (Test-Path -LiteralPath $temp) { Remove-Item -LiteralPath $temp -Force }
$children = Get-ChildItem -LiteralPath $source -Force
Compress-Archive -Path $children.FullName -DestinationPath $temp -CompressionLevel Optimal
Move-Item -LiteralPath $temp -Destination $dest -Force
```

打包后必须检查：

- zip 入口层级从 `Contents\mods\GodSystem\...` 开始。
- `GodSystem_Items.txt` 里 `SystemCoin1/10/100` 都是 `ItemType = base:normal`。
- zip 中没有 `damnlib` 或 `RuinBazaar`。

## 常见错误

- 游戏提示缺少 `mod.info`：通常是目录层级放错。
- Workshop 页面能进但上传失败：检查 `preview.png` 和 `Contents` 是否在上传目录第一层。
- 玩家新版仍报旧行号：多数是重复启用旧版或没有清理本地旧包。
- 启用 `damnlib` 后正常、不启用就红字：优先检查 GodSystem 自己的物品脚本字段，不要直接把 `damnlib` 加进依赖。

## 发布原则

- 用户本地确认成功后，再覆盖 `GodSystem_v1.15.3_B42_WorkshopUpload.zip`。
- 未经用户确认的新实验版不要覆盖当前稳定 zip。
- 需要新版本时，新建新 zip，保留 v1.15.3 稳定备份。
