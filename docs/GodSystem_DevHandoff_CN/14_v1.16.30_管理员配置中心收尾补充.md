# v1.16.30 管理员配置中心收尾补充

## 本次补充

在管理员配置中心初版基础上，补齐两个容易遗漏但后续会影响维护的点：

1. 管理员页复用底部搜索框，搜索范围包含配置 key、配置分组、配置类型、物品 fullType、详情文本。
2. 管理员页入口、编辑、重置、物品覆盖、格式提示、选择提示等文案写入 `GodSystem_Localization_Override.lua`，优先走 Lua fallback 本地化，减少 Translate 文件编码或加载顺序带来的风险。

## UI 行为

- 单人模式默认显示“管理”工具按钮。
- 多人模式只有服务器 state 下发 `admin=true` 后显示“管理”工具按钮。
- 管理员页底部按钮顺序为：搜索框、编辑、刷新、重置。
- 物品覆盖输入格式继续使用：

```text
Base.Axe|buy=500,sell=25,cat=weapon,shop=1,recycle=1,lottery=1
```

## 开发注意

- 管理员页搜索复用了商店/回收页的搜索框，因此修改 `onShopSearchChange()` 时必须保留 `shopSearchPurpose == "admin"` 分支。
- `setShopLayout()` 现在也承担管理员页搜索框布局，不要只按商店/回收页理解这个函数。
- 新增管理员文案时继续优先写入 `GodSystem_Localization_Override.lua`，中文用 UTF-8 byte escape 形式，避免 PowerShell 控制台编码影响 Lua 文件。
- 导入/导出本版本不做。以后如需做，基于 `GodSystem_AdminConfig.buildSnapshot()` 设计，不要另起一套配置格式。
