## 2. 快捷键边界

新增 `GodSystem_PanelKey.lua`：

- 使用 B42 `PZAPI.ModOptions` 注册稳定选项 `OpenPanelKey`，默认 `N`。
- 模块不读取 Core、Server、任务、经济或存档；主 UI 只通过 `registerToggle(callback)` 注入面板开关。
- 顶部工具区保留“快捷”，另加“设置”。设置仍使用主窗口现有单列页面，不创建第二套窗口或滚动列表。
- 设置页可显示当前按键、捕获下一次按键、恢复默认 N；Esc 取消捕获。
- 游戏原生 Mod Options 和系统设置页读写同一个 keybind 对象。
- 无玩家、聊天/文本框获得焦点、确认弹窗存在和捕获按键期间不会开关系统面板。
- 冲突按键允许保存，只向玩家说明，不修改其他 Mod 或原版绑定。

## 3. 任务排序边界

新增纯模块 `GodSystem_TaskOrder.lua`：

- 不注册事件，不读写 ModData，不依赖 UI/Core/Server。
- `sortedCopy(tasks, status, titleProvider)` 只返回显示副本，不重写 `data.tasks`。
- 分类顺序为击杀、回收、生存、提交、消费、购买、移动、未知。
- 同分类按现有罚金阈值排列为 D1、D2、D3、D4，再按本地化标题和稳定任务 ID 排序。
- 待接任务、进行中任务和任务追踪器在每次重建时重新使用该排序器，因此生成、刷新或 MP 状态包的输入顺序不会覆盖显示顺序。
- `GodSystem.getTaskDifficulty()` 复用同一阈值，避免标题 D 级与排序规则分叉。
- 现有列表选择恢复继续使用 `taskId`，没有插入分类标题行，也没有改变列表行数和任务操作语义。

## 5. 实机验收

### SP

1. 新档和 42.20.1.7 旧档分别按 N 打开、再按 N 关闭面板。
2. 顶部“快捷”仍打开原快捷窗；“设置”能修改按键、Esc 取消、恢复默认 N。

4. 聊天框、搜索框和确认弹窗期间按快捷键不误开关面板。
5. 同时存在多种分类和 D1–D4 任务时，待接、进行中和追踪器顺序一致；刷新和接取后顺序不回退。
