# v1.16.36 快捷动作栏与左侧翻页方案
## 目标

基于当前 `v1.16.35` 实时测试目录继续开发 `v1.16.36`。本版不改稳定包，只修改：

- 快捷悬浮窗从“打开页面入口”改为“直接执行常用动作”。
- 左侧主导航从只依赖滚轮滚动，改为显式上翻/下翻按钮分页。

## 快捷动作栏

快捷窗继续用当前 `GodSystemShortcutWindow`，保留可拖动和位置保存，但按钮改成四个动作：

- `回家`：仅在已经设置家园点时显示，点击后走原家园传送确认、扣费、安全落点和多人传送确认流程。
- `返回`：仅在存在出发点时显示，点击后走原返回确认、扣费、安全落点和多人传送确认流程。
- `卖腰包`：执行系统腰包一键出售全部物品，等同腰包页“一键出售全部”，多人走服务端 `recycleWaist`。
- `存现金`：把背包内所有实体系统币存入银行活期。单人本地扫描实体系统币，多人由服务器扫描真实背包货币、移除实体钱币、写入活期，避免客户端和服务器余额不同步。

不再保留任务、抽奖、商城、回收、银行、家园等打开页面入口。

## 左侧导航翻页

左侧导航保留原按钮结构，但不再让玩家必须依赖滚轮才能发现后续功能：

- 左侧导航顶部增加上翻按钮。
- 左侧导航底部增加下翻按钮。
- 中间区域只显示当前页能完整放下的功能按钮。
- 每次翻页跳过一整页可见按钮，不显示半截按钮。
- 滚轮可以保留为辅助操作，但行为改为翻页或按整页步进，不作为唯一入口。
- 当已经在第一页时，上翻按钮禁用或弱化；当已经在最后一页时，下翻按钮禁用或弱化。

这样即使玩家不知道滚轮，也能看到有明确的上下翻页控制。

## 单人/多人原则

- 传送继续复用现有家园系统，不绕过确认和安全落点。
- 腰包出售继续复用现有腰包回收路径。
- 存入全部现金是银行动作，不新增独立协议；复用现有 `bank` 命令并新增 `depositAllCash` action。
- 多人模式下涉及实体钱币变化的部分由服务端执行。

## 风险点

- 快捷窗不应该为了执行动作打开主系统窗口，否则仍然会像旧版快捷入口。
- `存现金` 不能只相信客户端传来的金额；多人必须服务端扫描玩家真实背包。
- 左侧导航翻页按钮不能挤占普通功能按钮导致底部再次越界。
