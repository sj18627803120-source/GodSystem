# v1.16.44 银行借贷本地化乱码修复

## 背景

用户截图反馈：v1.16.43 银行页旧有文本正常，但新增借贷行、借贷详情和相关按钮显示为 `7>2000`、`SM 3d` 等乱码或残缺字符。

本次基于 v1.16.43，只修复本地化与版本记录，不改变银行借贷业务逻辑。

## 根因

1. `Translate\CN\IG_UI_CN.txt` 和 `Translate\CH\IG_UI_CH.txt` 中 v1.16.43 新增的借贷表项缺少行尾逗号。PZ 的翻译表对语法容错有限，缺逗号会导致后续键解析异常或回落到 fallback。
2. `GodSystem_Localization_Override.lua` 中 v1.16.43 新增的借贷 fallback 文本不是稳定的 ASCII 字节转义形式。GodSystem 运行时优先读取该 Lua fallback，直接中文或错误编码会在游戏里显示成乱码。

## 修复

- 版本号提升到 `1.16.44`：
  - `Contents\mods\GodSystem\42\media\lua\shared\GodSystem_Config.lua`
  - `Contents\mods\GodSystem\mod.info`
  - `Contents\mods\GodSystem\42\mod.info`
- 补齐 CN/CH Translate 借贷表项行尾逗号。
- 将 `GodSystem_Localization_Override.lua` 中借贷 UI、提示、历史和管理员借贷配置 fallback 全部改为 ASCII-only UTF-8 十进制字节转义。
- `README_创意工坊上传说明.md` 更新到 v1.16.44。
- 新增专项测试 `C:\Users\Admin\Desktop\PJ\Test-GodSystemV11644.ps1`：
  - 检查三处版本号都是 `1.16.44`。
  - 检查借贷 CN/CH Translate 表项都以逗号结尾。
  - 检查借贷和管理员借贷 fallback 都存在。
  - 检查这些 fallback 值只含 ASCII，避免再次混入直接中文或 mojibake。
  - 检查 UI 仍引用借贷本地化 key。

## 后续规则

- 不要用 PowerShell 控制台显示效果判断中文文件是否乱码。控制台可能只是显示编码不一致。
- Translate 文件可以保留正常 UTF-8 中文，但 `IGUI_GodSystem_* = "..."` 表项必须保持逗号。
- `GodSystem_Localization_Override.lua` 是运行时关键 fallback。新增中文 fallback 时，优先使用 UTF-8 十进制字节转义，保持源码字符串 ASCII-only。
- 修改翻译、Lua fallback 或说明文本后，必须运行：

```powershell
powershell -ExecutionPolicy Bypass -File 'C:\Users\Admin\Desktop\PJ\Test-GodSystemEncoding.ps1' -Root 'C:\Users\Admin\Zomboid\Workshop\GodSystem' -IncludeDocs
```
