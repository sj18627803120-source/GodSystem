# v1.16.43 银行借贷系统实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有银行页加入首版借贷系统：单笔贷款、活期还款、逾期破产、追债僵尸、SP/MP 同步、管理员配置和本地化。

**Architecture:** 沿用现有 `bank` 数据结构和 `performBankAction` / `Commands.bank` 命令通道。单人客户端和多人服务端分别实现同名贷款 helper，UI 只做展示和命令触发。借款本金进入活期，贷款不生成实体现金。

**Tech Stack:** Project Zomboid B42.19 Lua；PowerShell 静态测试；Lua 5.1 `luac -p`；GodSystem 现有 CN/CH/override 本地化。

## Global Constraints

- 实时开发目录：`C:\Users\Admin\Zomboid\Workshop\GodSystem`。
- 版本从 `1.16.42` 升到 `1.16.43`。
- 每次版本升级必须滚动备份，保留最新 20 个版本。
- 首版只允许一笔未结清贷款。
- 手动还款只扣活期，背包现金必须先存入活期。
- 信用破产不清死期存款。
- 玩家死亡不清空贷款，欠款依旧要还。
- 不在 UI 绘制、高频刷新、鼠标悬停路径做递归背包扫描。
- 多人模式银行贷款以服务端为准。
