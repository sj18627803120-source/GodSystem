- 新增客户端纯 UI helper `GodSystem_ListState.lua`。它只捕获/恢复列表滚动、稳定选中 key 和行索引，不访问服务端、不写业务数据。
- 主系统按页面、分类、搜索、排序和筛选建立列表上下文；购买、回收、取出、隐藏、任务和银行等业务刷新保留同一上下文的滚动和有效选择。上下文变化仍从顶部开始。
- 仓库存取页分别恢复来源、人物物品、网络仓库和详情四栏。现有 Ctrl/Shift 多选、数量菜单、“存入选中”和“取出选中”保持不变；仓库管理页继续是单容器配置页。
- 商店隐藏管理增加复选框、Ctrl/Shift 多选、选中数量与批量隐藏/恢复。批量操作只改变符合目标状态的项目；无效、已变化或无权限项计入跳过。删除上架仍是单选确认操作。
- 新增 `setShopItemsHidden` C2S 命令，保留 `setShopItemHidden` 单件兼容命令。客户端排序去重，服务端重新验证玩家记录、单批限制 500 项、一次保存/状态发送，并回传请求数、变更数、跳过数和 key 列表。
- 操作指纹纳入目标状态和规范化后的 key 集合；同一操作 ID 的语义重试复用首个结果，不会因为重复或空 key 被误判为不同请求。
