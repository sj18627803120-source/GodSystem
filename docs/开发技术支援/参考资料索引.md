## 使用原则

1. **同补丁优先**：B42.20.4 原版 Lua/Java 是第一手证据
2. **旧版只作线索**：B42.19 及更早资料的方法签名必须复核
3. **参考 MOD 不复制代码**：仅提供事实、路径和接口线索
4. **实机验证不可替代**：Kahlua/Lua 测试不证明 Java 重载和多人同步
