## 核心约束

1. **服务端权威**：客户端副本只用于展示，不作为权限或余额来源
2. **幂等交易**：付费/发货使用 `opId` + 指纹，重试返回原结果，不重复扣费
3. **价格参考顺序**：管理员覆盖 → `GodSystem_Prices.lua` 精确价 → 分类默认价
4. **不猜 API**：同补丁原版代码/反编译优先，历史 B42.19 资料只作线索
5. **版本同步**：功能升级须同步 `mod.info` ×2、`Config.Version`、`workshop.txt`、交接文档

## 3.21.3 地面回收

原生世界移除成功后不重复执行生命周期；异常或暂时核验失败后进行一次有界状态复查，确认身份、两个地块列表及世界引用全部清除才结算。失败诊断带步骤和异常摘要。全部恢复并确认失败的地面回收可自动原版拾取后按背包回收一次；多人需匹配操作回执，等待原生物品与背包同步，不对超时/未知结果启动备用。用户确认回收正常，详见[交接128](../GodSystem_DevHandoff_CN/128_v42.21_3.21.3_地面回收核对与备用拾取.md)。
